# CDP 서버 관리자 설명서

> 공식 사이트의 화면용 **줄인 판**이다. 실제 설명서는 설치된 서버의 `/manual` 에 있다.

## 목차

0. 서버 관리자가 맡는 것 · 2. 서버 설치 · 3. 사람 — 명부와 토큰 · 4. 큐레이터 맡기기 · 5. 지식 레포 세우기 · 8. 갱신 · 10. 장애 대응

## 0. 서버 관리자가 맡는 것

서버 · 명부 · 지식 레포를 세우고, 레포마다 큐레이터를 맡긴다. 관리 문서의 글은 큐레이터의 일이다.

## 2. 서버 설치

```
sudo bash deploy/install.sh --bind <서버IP>
```

설치가 셸에 찍은 코드로 브라우저 `/setup` 에서 첫 관리자를 만든다. `ctx serve doctor` 가 fail 0 이면 끝이다.

## 3. 사람 — 명부와 토큰

역할은 셋 — viewer · writer · admin. 토큰 원문은 **한 번만** 보인다. 서버는 해시만 둔다.

## 4. 큐레이터 맡기기

서버 › 사용자의 「레포 × 큐레이터」 — 체크 하나가 그 사람의 `curate` 한 줄이다. admin 은 모든 레포의 큐레이터이고, viewer 는 될 수 없다.

## 5. 지식 레포 세우기

서버 › 지식 레포 › 새 지식 레포 — **빈 틀**로 선다. 옛 레포가 있으면 작업 기록만 옮겨 와 큐레이션부터 다시 세운다.

## 8. 갱신

`upgrade.sh` 한 줄. 작업 레포는 설치 한 줄 `--update` 로 새 판의 에이전트 세팅을 받는다.
