# CDP 관리자 설명서

> 공식 사이트의 화면용 **줄인 판**이다. 실제 설명서는 설치된 서버의 `/manual` 에 있다.

## 목차

1. 관리자가 맡는 것 · 2. 받는 것 · 3. 서버형 설치 · 4. 로컬형 설치 · 6. 사람 관리 · 7. 지식 레포 운영 · 9. 갱신 · 10. 장애 대응

## 1. 관리자가 맡는 것

서버 · 지식 레포 · 명부를 세우고, 어휘와 등록부를 지킨다.

## 3. 서버형 설치

```
sudo bash deploy/install.sh --bind <서버IP>
```

설치가 찍은 코드로 브라우저 `/setup` 에서 첫 관리자를 만든다. `ctx serve doctor` 가 fail 0 이면 끝이다.

## 6. 사람 관리 — 명부와 토큰

역할은 셋 — viewer · writer · admin. 토큰 원문은 **한 번만** 보인다. 서버는 해시만 둔다.

## 9. 갱신

`upgrade.sh` 한 줄. 지식 레포의 에이전트 세팅도 새 판으로 간다.
