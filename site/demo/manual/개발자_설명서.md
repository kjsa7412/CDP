# CDP 개발자 설명서

> 공식 사이트의 화면용 **줄인 판**이다.

## 목차

1. CDP 가 무엇인가 — 개발자의 눈으로 · 2. 구조 · 5. 검증 · 6. 릴리스 · 8. save · 9. MCP · 10. 큐레이션 · 다음 할 일

## 2. 구조

화면 · CLI · MCP 서버가 **같은 계산**(`core/`)을 부른다. 답이 갈리지 않는다.

## 5. 검증

```
node --test test/
npm run verify
```

## 6. 릴리스

태그 `v<판>` 을 push 하면 Release 에 셋이 붙는다 — 서버 tar · 사이트 zip · SHA256SUMS. tar 는 이름을 NFC 로 싼다(`core/tar.js`).

## 8. save

쓰는 길은 하나다. writer 는 작업 기록만, 큐레이터는 판정 · 섹션 · 등록부까지 — 한 save 가 한 커밋이다.

## 10. 큐레이션 · 다음 할 일

대기열 · 미반영 · 기록 상태는 저장하지 않고 계산한다(`core/curation.js`). 「시작하기」 줄은 `core/nextsteps.js` 한 곳 — 화면은 `GET /next`, `ctx up` · 설치기는 끝 출력으로 같은 줄을 낸다.
