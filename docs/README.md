# docs — 우리만 보는 것

**여기 있는 것은 받는 사람에게 가지 않는다.** 받는 사람에게 가는 것은 `agent/`(스킬 · CLAUDE 블록 → 서버 번들 `kit/` · 서식집 → `forms/`)와 `manual/` 에 있다. **역할별 제품 설명서**는 [`../manual/`](../manual) 이 원천이다 — 지금 사용자 · 관리자 · 개발자 셋이고, v1.0 은 큐레이터 책을 더해 넷이 된다(개편안 §6.4 · W9).

이 폴더의 판정 기준은 하나다 — **보존되는가.**

| 폴더 | 보존 | 무엇 |
|---|:--:|---|
| `design/` | **O** | 설계서. **v1.0 의 정본은 v2 세트**(아래 「어디부터 읽나」 첫 다섯 줄)다. 나머지는 이력이고, 문서마다 맨 위 한 줄이 무엇이 대신하나를 말한다 |
| `관리문서패키지/` | 이력 | 패키지 시절 `public-si`(옛 dpms) 패키지를 만든 분석과 템플릿 규약. v1.0 은 패키지가 없다 — 서식의 규약은 [`design/CDP_서식집_규약_v1.0.md`](design/CDP_서식집_규약_v1.0.md) |
| `그림/` · `용어.md` | **O** | 구조 그림 · **말의 정본**([`용어.md`](용어.md) v1.0 — 정본 한 곳) |
| `dev/` | **X** | 개발 메모 · TODO · 검토 기록. 끝난 단계의 이력이다. 지워도 설계서가 남는다 |
| `attic/` | 이력 | **한 번 돌고 끝난 것.** 다시 돌리지 않는다. *"어떻게 만들어졌나"* 에 답하는 유일한 기록이라 남긴다 |

**어긋나면** — `dev/` 와 `design/` 이 어긋나면 `design/` 이 맞다. `design/` 안에서는 **v2 세트**가 맞다. v2 세트와 코드가 어긋나면 **코드가 맞다** — 각 문서의 「어긋난 곳」 절이 그 자리를 적는다.
