# docs — 우리만 보는 것

**여기 있는 것은 받는 사람에게 가지 않는다.** 받는 사람에게 가는 것은 전부
`agent/` 에 있다(그 폴더의 판정 기준 — *"받는 사람에게 가는가"*). **세 역할의 제품 설명서**
(사용자 · 관리자 · 개발자)는 [`../manual/`](../manual) 에 있다 — 그것이 원천이다.

이 폴더의 판정 기준은 하나다 — **보존되는가.**

| 폴더 | 보존 | 무엇 |
|---|:--:|---|
| `design/` | **O** | 설계서. 프로토콜 · 작업환경 · 수행 · 시스템 · MCP · 제품화 검토. **고칠 사람이 먼저 읽는다** |
| `관리문서패키지/` | **O** | dpms 패키지를 만든 분석과 규약. 두 번째 패키지가 이것을 공유한다 |
| `그림/` · `용어.md` | **O** | 구조 그림 8장 · 고치는 사람의 말 |
| `dev/` | **X** | 개발 메모 · TODO · 검토 기록. 끝난 단계의 이력이다. 지워도 설계서가 남는다 |
| `attic/` | 이력 | **한 번 돌고 끝난 것.** 다시 돌리지 않는다. *"어떻게 만들어졌나"* 에 답하는 유일한 기록이라 남긴다 |

**`dev/` 에 든 것이 `design/` 과 어긋나면 `design/` 이 맞다.** `dev/` 는 그때의
생각이고 `design/` 은 구현이 도달한 자리다.

| | |
|---|---|
| `build_gdi_repo.py` · `import_ops_issues.py` · `data/` | GDI 실물에서 첫 지식 레포를 역으로 만든 스크립트와 입력. **개인 PC 경로가 박혀 있다** |
| `dpms-패키지/` | DPMS 산출물 → `agent/packages/dpms` 를 어떻게 만들었나. 변환기는 원본 xlsx 가 없으면 돌지 않는다 |
| `이집이지_이관/` | 다른 프로젝트의 지식 폴더 777건을 CDP 로 옮긴 설계 5편. 끝난 일이다. **다만 그 규칙은 `core/importdir.js`(`ctx import-dir`)가 인용한다** — 프로젝트와 무관한 부분만 |

`ops/` 는 **운영 명령**이다. `attic/` 것은 명령이 아니라 지나간 일이다.
