- [x] 그 문장이 지금도 살아 있는지 확인 — `agent/README.md` 7행에 있다

재편 당일**이다. 이름이 나중에 실패한 사례가 아니라 재편하면서 걸러낸 것이다.

## 2. `core/` 승격

### 왜

`core/` 는 앱과 `ctx` **양쪽의 상위 개념**인데 폴더로는 앱(`viewer/`) 밑에 있다.
개념 계층과 폴더 계층이 뒤집힌 유일한 자리다. *"ctx 는 viewer 의 일부인가"* 라는
질문이 반복해서 나오는 원인이다.

```
지금                          바꾼 뒤
viewer/server/core/   13      core/          13   계산 — 정본
viewer/server/                viewer/server/      앱 서버
viewer/bin/                   viewer/bin/         ctx 소스
```
