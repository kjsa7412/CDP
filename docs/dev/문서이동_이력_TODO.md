## ① 문서 · 섹션을 주소에

주소 — 로컬 `/d/<id>` · 서버형 `/r/<레포>/d/<id>`. `<id>` 는 작업문서 id 또는 관리 · 기타 문서의 경로(`docs/테이블정의서.md`)이고
조각마다 인코딩해 `/` 로 잇는다. 섹션(좌표)으로 가는 이동은 `?at=<값>` — 해시는 본문 안 `#앵커` 링크가 쓰므로 건드리지 않는다.

**바뀌는 파일** — `viewer/src/lib/doclink.js`(새 · 순수 함수) · `viewer/src/lib/router.jsx`(`navigate` 가 history state 를 받는다) ·
`viewer/src/App.jsx` · `viewer/server/adapter/http.js`(로컬 SPA 폴백 — `/d/…` 는 `.md` 로 끝나도 index.html).

- [x] `openDoc` 은 주소만 바꾼다. 주소 → 문서는 한 길(`applyDoc`) — 읽음 · `lastDoc` · 바뀜 표시 · 좁은 창 덮개 걷기가 뒤로 · 앞으로에도 돈다
- [x] 히스토리 항목마다 왼쪽(뿌리 · 찾기/뻗어나가기 · 범위)을 싣고, 돌아오면 그대로 되살린다 — 검토 H4
- [x] 첫 화면 — 주소에 문서가 없을 때만 `lastDoc` 을 열고 주소를 그 문서로 **바꿔 쓴다**(replace)
- [x] 그래프 · 관리에서 「문서」 로 오면 보던 문서의 주소로
- [x] `j` · `k` 훑기는 `replace` — 이력에 쌓지 않는다(H8)
- [x] 메모리 스택(`historyRef`)을 지우고 `Alt+←` · `Alt+→` 는 `history.back()` · `forward()` — **입력칸 안에서는 손대지 않는다**(H7)
- [x] 본문 링크의 basename(`테이블정의서`)은 관리 문서 경로로 맞춘다 — 같은 문서가 주소 둘 · 탭 둘이 되지 않게
