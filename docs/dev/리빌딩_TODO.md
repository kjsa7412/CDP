## ② 스냅샷 — 정본을 기록으로 되돌린다

- [ ] `recordKind` 에 `snapshot`(프론트매터 `snapshot: { source, asof }`) — 대기열 · 미반영 계산이 `baseline` 처럼 뺀다
- [ ] `save` 입력 `snapshot: [{ coord }]`(≤200 · 큐레이터만 — `curatorOnly` 에 더한다)
  - [ ] 서버가 섹션 `content` 를 읽어 기록을 짓는다 — 본문 · `source: docs/<문서>.md@<sha>#<헤딩>` · `date` = 섹션 줄 blame 최댓값 · `touches: [coord]` · id `<YYYY-MMDD>-스냅샷-<슬러그>`
  - [ ] 섹션이 없거나 비었으면 거절(`E_INPUT` · 좌표) · 이미 원천이 있으면(unsourced 아님) 경고하고 건너뛴다
  - [ ] 같은 save 에 큐레이션 기록 하나 — `curates: [{ id: <스냅샷>, verdict: reflect, into: [coord] }]` · `tags: [rebuild, snapshot]` · 한 커밋
  - [ ] `sections` · `baseline` · 사람의 `curates` 와 한 save 에 섞지 않는다(기준선과 같은 규칙)

- [ ] `--records-from` 이 스냅샷도 옮기는지 확인(옮긴 스냅샷은 새 레포에서 대기열에 선다 — 판정 기록은 옮기지 않으므로)
