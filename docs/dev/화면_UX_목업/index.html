6. 사람 관리 — 명부와 토큰

서버형에만 있다. 로컬형은 git 원격의 권한이 곧 권한이다. 콘솔 /console 에서 한다 — 관리자(admin)만 들어간다.

6.1 모델 — 권한은 사람에게, 토큰은 신원만

권한은 사람(users[])에 붙는다. 토큰은 "이 사람이다" 만 증명한다. 사람의 역할 · 레포를 바꾸면 그 사람의 토큰 전부에 즉시 먹는다.

6.2 사람을 추가한다

콘솔 > 사용자 > [+ 사용자] — 이름(아이디) · 라벨 · 역할 · 볼 수 있는 레포. 저장하면 그 행의 [발급] 으로 이어진다.

6.3 토큰을 발급한다

콘솔 > 토큰 > [발급] — 사용자 · 메모(기기) · 만료. 원문은 다음 화면에 한 번 보인다.

(본문 계속 …)
