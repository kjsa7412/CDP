## G. 관리문서 보강 — 설명과 예제

골격은 **머리 표 + 빈 예시 + 일반 작성지침**뿐이다. 받는 사람이 *"여기에 뭘
어떻게 적으라는 건가"* 를 알 수 없다.

문서마다 셋을 넣는다.

| | 무엇 | 왜 |
|---|---|---|
| **설명** | 무엇 · 언제 · 누가 | 머리 표는 관리번호만 말한다 |
| **여기 적지 않는 것** | 다른 문서로 가는 경계 | **실무에서 제일 자주 섞인다** — 목록에 내용을 쓰고 사양서에 목록을 쓴다 |
| **채워진 예시** | 그 문서의 한 단위 | 빈 표를 주면 컬럼 뜻을 짐작해야 한다 |
| **문서별 작성지침** | 항목마다 작성방법 · 필수 | 지금은 46개가 같은 표다 |

**원천은 DPMS 실물이다.** 구조는 [`02_문서분석.md`](02_문서분석.md) §3 에 이미
적혀 있다 — 다시 열지 않고 그것을 쓴다.

> **예시 값은 실물이 아니라 서식이다.** `rp_plnd_mst` 같은 실제 GDI 이름을
> 쓰면 받는 사람이 자기 것으로 착각한다. **모양은 진짜처럼, 값은 명백히
> 예시로** — `ex_` 접두와 `(예시)` 표시를 쓴다.
