# 용어

CDP 소스와 설치 문서에 나오는 말들. **뜻보다 "왜 여기서 그 말이 나오나"** 를 적는다.

그림은 [그림/](그림/) 에 있다.

---

## 1. 파일과 실행

| 용어 | 뜻 | CDP 어디서 |
|---|---|---|
| `.js` | 자바스크립트 소스 파일 | `viewer/server/core/*.js` |
| `.mjs` | **m**odule JS. "이 파일은 ESM 방식"이라고 확장자로 못박은 것 | `bin/ctx.mjs` · `ops/lib/*.mjs` |
| `.cjs` | 옛 모듈 방식(CommonJS) | exe 안 번들 |
| `.cmd` | 윈도 배치 스크립트 | `bin/ctx.cmd` |
| sh | 유닉스 셸 스크립트. 확장자가 없는 것이 보통 | `bin/ctx` · `.githooks/pre-commit` |
| 셔뱅(shebang) | 파일 첫 줄 `#!/usr/bin/env node`. "이 파일은 node 로 실행해라" | 번들 맨 앞줄 |
| 실행 권한 | 유닉스에서 "실행해도 된다"는 표시(`chmod 755`) | `build-ctx.mjs` 가 `bin/ctx` 에 붙인다 |

**셔뱅이 CDP 에서 무서운 자리** — `pre-commit` 이 CRLF 로 체크아웃되면 셔뱅 뒤에 보이지 않는 문자가 붙어 실행되지 않는다. 커밋은 통과하고 검사만 조용히 사라진다.

## 2. 모듈

**모듈 = 파일 하나.** 코드를 파일로 나누고, 서로 필요한 것만 주고받는 방식이다.

```js
// vocab.js — 내보낸다
export function parseVocab(text) { ... }

// repo.js — 가져다 쓴다
import { parseVocab } from './vocab.js'
```

`export` 하지 않은 것은 그 파일 밖에서 보이지 않는다. 이름이 겹쳐도 충돌하지 않고, 어느 파일이 어느 파일에 기대는지가 `import` 줄에 드러난다.

CDP 가 모듈을 나눈 기준은 **계산을 한 곳에 두는 것**이다. `core/repo.js` 하나를 앱과 `ctx` 가 함께 `import` 한다. 나누지 않고 양쪽에 베껴 두면 둘이 갈라지고, 그때 사용자는 어느 쪽을 믿을지 알 수 없다.

### ESM 과 CJS

같은 일을 하는 두 세대다. 문법만 다르다.

| | 가져오기 | 내보내기 | 확장자 |
|---|---|---|---|
| ESM (최신) | `import x from 'y'` | `export` | `.mjs` 또는 `.js` |
| CJS (옛것) | `const x = require('y')` | `module.exports` | `.cjs` 또는 `.js` |

`.js` 는 둘 다 될 수 있어서 `package.json` 의 `"type"` 설정을 봐야 한다. **`.mjs` 는 그 모호함을 없앤 이름이다** — 설정과 무관하게 ESM 이다. `ops/lib/*.mjs` 가 그래서 `.mjs` 다.

`bin/ctx.mjs` 는 ESM 단일 파일이고, exe 안 번들은 CJS 다. SEA 가 CJS 를 요구하기 때문이지 우열이 있어서가 아니다.

## 3. 실행 환경

| 용어 | 뜻 | 왜 중요한가 |
|---|---|---|
| Node | 자바스크립트를 브라우저 밖에서 돌리는 프로그램 | **폐쇄망 PC 엔 없다고 전제한다.** 그래서 exe 폴백이 있다 |
| 런타임 | 그 "돌려주는 엔진" 자체 | SEA 는 런타임을 exe 안에 품는다 |
| `node_modules` | 남이 만든 라이브러리가 쌓이는 폴더. 수천 개 파일 | 지식 레포엔 없다. 그래서 번들이 필요하다 |
| 의존성 | 내 코드가 돌려면 있어야 하는 남의 코드 | `ctx` 는 의존성 0 이 목표다 |
| 네이티브 모듈 | C/C++ 로 짜여 OS 마다 다시 컴파일해야 하는 라이브러리 (예: SQLite) | **하나도 안 썼다.** 썼으면 SEA 가 불가능했다 |

## 4. 빌드

| 용어 | 뜻 |
|---|---|
| 번들 | 수백 개 파일을 **한 파일로 합치는 것**. `import` 를 따라가며 코드를 펼쳐 넣는다 |
| 번들러 | 그 일을 하는 도구. 여기선 esbuild |
| 산출물 | 빌드가 만들어낸 파일. 손으로 고치면 다음 빌드에 날아간다 |
| 인라인 | 밖에 있던 것을 코드 안에 박아 넣는 것 |
| base64 | 이진 파일을 글자로 바꾸는 방식. 그래야 코드 안에 들어간다 |
| blob | 이진 덩어리. SEA 가 exe 안에 끼워 넣는 코드 뭉치 |
| SEA | Single Executable Application. `Node 런타임 + 내 코드` 를 exe 하나로 붙이는 Node 공식 기능 |

```
평소   node 설치 → 내 코드 실행
SEA    cdp.exe 하나 (안에 node 가 들어 있다)
```

**번들이 조용히 낡는 것이 실제 함정이다.** 소스를 고치고 재번들하지 않으면 지식 레포의 `bin/ctx.mjs` 는 옛 명령 목록으로 돈다. `ctx version` 으로 세 곳(`bin/` · `tools/cdp.exe` · 배포본)이 같은지 본다.

## 5. 명령줄

| 용어 | 뜻 |
|---|---|
| CLI | Command Line Interface. 창 없이 명령으로 쓰는 프로그램 |
| 인자 | 명령 뒤에 붙는 값. `ctx where PS002` 의 `PS002` |
| 플래그 | `--json` `--dry` 처럼 켜고 끄는 옵션 |
| exit code | 끝날 때 남기는 숫자. 사람은 잘 안 보지만 훅과 스크립트는 이것만 본다 |
| stdout / stderr | 정상 출력 / 오류 출력 |
| CP949 | 윈도 한국어 콘솔의 옛 인코딩. `—` 같은 문자가 깨져 `ctx` 는 ASCII 구두점만 쓴다 |

```
0    정상
1    검사 실패 - 고쳐야 한다
2    사용법 틀림 · 지식 레포 못 찾음
127  도구가 없다 - 훅이 건너뛴다
```

**127 과 1 을 가르는 것이 핵심이다.** 실행기가 없을 때 1 을 냈더니 훅이 "검사 실패"로 읽고 커밋을 막았다. 메시지는 "고친 뒤 다시 커밋하세요"라 사용자는 자기 문서가 잘못된 줄 안다.

## 6. git

| 용어 | 뜻 |
|---|---|
| 훅(hook) | git 이 특정 시점에 자동 실행하는 스크립트 |
| `pre-commit` | 커밋 **직전**에 도는 훅. 0 이 아니면 커밋이 취소된다 |
| `core.hooksPath` | 훅을 어느 폴더에서 찾을지. **clone 을 따라오지 않아** 각자 한 번 건다 |
| `.gitattributes` | 파일별 취급 규칙. 여기선 줄바꿈 고정용 |
| CRLF / LF | 줄바꿈 문자. 윈도는 CRLF, 유닉스는 LF |
| `git clone` | 원격 저장소를 통째로 복사 |
| `git bundle` | 저장소를 **파일 하나**로 말아내기. 폐쇄망 반입용 |
| ff (fast-forward) | 충돌 없이 그냥 따라붙는 병합. `ctx sync --pull` 은 이것만 한다 |

## 7. CDP 고유어

| 용어 | 뜻 |
|---|---|
| 좌표 | 이 시스템의 기본키. `PS002` · `EXA021` 같은 식별자 |
| 어휘 (`_vocab.md`) | 좌표 타입과 정본 이름·별칭 목록 |
| 등록부 (`_managed.md`) | 좌표 패턴 → 어느 관리 문서 어느 섹션인지의 매핑 |
| 정본 | 원본·기준이 되는 쪽. 복사본과 구분하는 말 |
| 파생 | 작업 기록의 변화를 관리 문서 섹션에 반영하는 것 |
| 지식 레포 / 작업 레포 | 문서가 있는 곳 / 코드가 있는 곳 |
| 포인터 파일 | 값이 아니라 **위치만** 담은 파일. `.claude/cdp.json` |
| skill | 클로드가 읽는 절차서. `.claude/skills/` 아래 폴더 하나가 하나 |
| 하네스 | 클로드를 실제로 돌리는 프로그램. 프로젝트 루트의 `.claude/skills/` 만 읽는다 |
| fixture | 테스트용 가짜 레포. `viewer/fixture/` — 실제 데이터가 아니다 |
| 폐쇄망 | 인터넷이 끊긴 망. CDN · 설치 · 업데이트를 못 쓴다는 뜻 |
