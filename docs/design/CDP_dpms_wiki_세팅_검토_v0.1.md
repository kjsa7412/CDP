2. **리허설** — 로컬 서버(v1 리허설처럼 `ctx serve` · 빈 틀 레포)에 A~D 를 그대로 돌리고 C 는 `ctx rebuild snapshot`, E~G 는 리허설 큐레이터 폴더(`ops/out/v1-rehearsal/curator-folder` 를 그 서버로)에서 묶음 하나씩 맛본다. 통과 — verify2 섹션 124/124 같음(G 전) · `check` 오류 0 · `drift` 근거 없음 0 · 대기 22 → E 뒤 3.
