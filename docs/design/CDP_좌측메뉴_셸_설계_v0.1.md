## 0. 한 줄

**메뉴가 지금 세 겹이다** — 상단 바의 얼굴 스위처(설명서 · 레포 ▾ · 콘솔) · 레포 얼굴 가운데의 세그(문서 · 그래프 · 관리) · 그 안쪽 왼쪽 메뉴 둘(관리의 현황 · 관리 문서 · 작업 레포 · 정보 / 콘솔의 현황 · 사용자 · 토큰 · 지식 레포 · 작업 레포 · 서버 · 감사). 이것을 **왼쪽 메뉴 하나**로 편다 — 위에 레포 고르기, 그 아래 묶음 넷(**지식 · 큐레이션 · 레포 관리 · 서버**)을 역할대로 보이고, 맨 아래 설명서와 내 계정. 접으면 아이콘 줄(56px)이 된다. 상단 바는 **접기 단추 · 위치(빵부스러기) · 검색 · 검증 · 동기화**만 남는다. 주소(`/r/<레포>/…` · `/console/…`)는 그대로라 링크 · 뒤로 가기 · 서버 라우트는 안 바뀐다.

## 1. 지금 — 메뉴 세 겹

| 겹 | 자리 | 항목 | 누가 |
|---|---|---|---|
| ① 얼굴 스위처 | 상단 바 왼쪽 | 설명서 · 레포 ▾(레포 메뉴) · 콘솔 | 콘솔은 admin |
| ② 레포 세그 | 상단 바 가운데(App 이 포털로) | 문서 · 그래프 · 관리 | 관리는 admin(서버형) |
| ③-a 관리 메뉴 | 관리 화면 안 왼쪽(`AdminView.MENU`) | 현황 · 관리 문서 · 작업 레포 · 정보 (로컬: 지식 레포 · 동기화 · 진단) | |
| ③-b 콘솔 메뉴 | 콘솔 화면 안 왼쪽(`Console.MENU`) | 현황 · 사용자 · 토큰 · 지식 레포 · 작업 레포 · 서버 · 감사 | admin |

- 「어디로 가나」 를 세 군데서 고른다. 관리 › 작업 레포 와 콘솔 › 작업 레포 처럼 **같은 이름이 다른 겹**에 있다.
- 관리자에게만 보이는 것(콘솔 · 관리)이 상단 바에 섞여 있어 writer 와 admin 의 화면이 **같은 줄에서 개수만 다르다**.
- 큐레이터 모델이 더하는 화면(대기열 · 이력 · 서식집)을 둘 자리가 ③-a 뿐인데, 그러면 매일 하는 일이 메뉴 세 번째 겹에 묻힌다.

## 2. 바뀐 뒤 — 왼쪽 메뉴 하나

```
┌──────────────────────┐
│ C CDP            «   │  ← 접기 (⌘B)
│ ┌──────────────────┐ │
│ │ dpms_wiki      ▾ │ │  ← 레포 고르기 (지금 「레포 ▾」 메뉴 그대로)
│ └──────────────────┘ │
│ 지식                  │
│  ▤ 문서              │  /r/<레포>/            관리 문서 · 섹션
│  ✎ 작업 기록      5  │  /r/<레포>/w           대기 수 (큐레이션)
│  ◇ 좌표 · 그래프      │  /r/<레포>/graph
│ 큐레이션          admin
│  ⧗ 대기열         5  │  /r/<레포>/manage/curation
│  ⟲ 이력              │  /r/<레포>/manage/curation/log
│  ▦ 서식집            │  /r/<레포>/manage/forms
│ 레포 관리         admin  ← 이 레포 하나
│  ✓ 현황              │  /r/<레포>/manage
│  ▤ 관리 문서          │  /r/<레포>/manage/docs
│  ⚇ 연결된 작업 레포   │  /r/<레포>/manage/work
│ 서버              admin  ← 서버 전부 (옛 콘솔)
│  ✓ 현황              │  /console
│  ▣ 지식 레포          │  /console/repos
│  ⚇ 작업 레포 대장     │  /console/workrepos
│  ☺ 사용자            │  /console/users
│  ⚿ 토큰              │  /console/tokens
│  ≡ 감사              │  /console/audit
│  ⚙ 서버 설정          │  /console/server
│ ─────────────────── │
│  📖 설명서            │  /manual (사이트 얼굴로 나간다)
│  (k) kjsa · admin  ⋯ │  내 토큰 · 테마 · 정보 · 로그아웃
└──────────────────────┘
```

### 2.1 역할별로 보이는 것

| 묶음 | viewer | writer | admin |
|---|:--:|:--:|:--:|
| 레포 고르기 | 할당된 레포 | 할당된 레포 | 전부 |
| 지식 (문서 · 작업 기록 · 좌표 · 그래프) | ○ | ○ | ○ |
| 큐레이션 (대기열 · 이력 · 서식집) | — | — | ○ |
| 레포 관리 (현황 · 관리 문서 · 연결된 작업 레포) | — | — | ○ |
| 서버 (현황 · 지식 레포 · 작업 레포 대장 · 사용자 · 토큰 · 감사 · 서버 설정) | — | — | ○ |
| 설명서 · 내 계정 | ○ | ○ | ○ |

- **권한 밖 묶음은 제목째 그리지 않는다**(D4). writer 의 메뉴는 지식 셋 + 설명서뿐이다 — 「무엇을 못 하나」 를 회색으로 보이지 않는다.
- 묶음 제목 옆의 작은 「admin」 표시는 admin 화면에만 보인다 — 자기가 보는 것이 관리자 전용임을 안다.
- 「정보」(판 · 단축키)는 내 계정 메뉴로 내린다 — 매일 갈 곳이 아니다.

### 2.2 이름을 고친 것

| 전 | 후 | 왜 |
|---|---|---|
| 관리 › 작업 레포 | 레포 관리 › **연결된 작업 레포** | 콘솔의 작업 레포(서버 전부의 설치 대장)와 같은 이름이었다 |
| 콘솔 › 작업 레포 | 서버 › **작업 레포 대장** | 위와 갈린다 |
| 콘솔 › 서버 | 서버 › **서버 설정** | 묶음 이름과 같았다 |
| 콘솔 | 묶음 「서버」 | 「콘솔」 은 화면 이름이지 하는 일이 아니다 — 레포 관리(하나) 對 서버(전부)로 범위가 보인다 |
| 레포 세그 「관리」 | 묶음 둘(큐레이션 · 레포 관리) | 매일 하는 큐레이션을 셋째 겹에서 꺼낸다 |

### 2.3 상단 바

```
[☰] dpms_wiki › 큐레이션 › 대기열          [검색 · 이동   Ctrl K]   ⟳ 동기화   ⚠ 검증 4
```

- 남는 것 — 접기(☰ · 접힌 때만 의미가 크다) · 빵부스러기(레포 › 묶음 › 화면) · 검색 · 동기화 상태 · 검증 칩. 
- 나가는 것 — 표식 메뉴 · 얼굴 스위처 · 레포 세그 · 내 이름(왼쪽 아래로).
- 레포 얼굴의 포털 자리(`slots.center · right`)는 그대로 쓴다 — 검색 · 검증 상태는 App 에 남는다.

### 2.4 접기

| | 펼침 (232px) | 접힘 (56px) |
|---|---|---|
| 보이는 것 | 레포 고르기 · 묶음 제목 · 아이콘 + 이름 + 배지 | 레포 첫 글자 칩 · 아이콘 · 배지 점 · 묶음 사이 구분선 |
| 이름 | | 마우스를 올리면 툴팁 · `aria-label` 은 늘 있다 |
| 바꾸는 법 | 맨 위 「«」 · 상단 바 ☰ · **⌘B / Ctrl B** | 같다 |
| 기억 | 사람마다 · 브라우저마다(`localStorage` · 실패해도 펼침으로 그린다) | |
| 좁은 화면 | ≤ 1100px 는 처음부터 접힘 · ≤ 760px 는 숨기고 ☰ 가 덮개(오버레이)로 연다 | |

- 문서를 읽을 때 왼쪽이 두 단이 된다 — **메뉴(232) + 찾기 목록(340) + 문서**. 지금 「⌘. 로 찾기 목록을 접는다」 는 그대로 두고, 메뉴는 ⌘B 로 따로 접는다. 문서 화면에 처음 들어갈 때 자동으로 접지 않는다 — 사람이 정한 상태를 화면이 바꾸지 않는다(L4).
- 접힌 상태에서 레포 고르기는 첫 글자 칩 — 누르면 지금과 같은 레포 메뉴가 옆으로 뜬다.

## 3. 얼굴은 어떻게 되나

| 얼굴 | 왼쪽 메뉴 | |
|---|---|---|
| 레포(`/r/<레포>/…`) | **있다** | 지식 · 큐레이션 · 레포 관리 · 서버 |
| 콘솔(`/console/…`) | **있다 — 같은 메뉴** | 서버 묶음이 켜진다. 레포 고르기는 마지막으로 본 레포를 보인다. 콘솔 안쪽의 왼쪽 메뉴(③-b)는 없어진다 |
| 로컬(`ctx serve` 없이 이 PC) | 있다 | 레포 고르기 대신 레포 이름(고정) · 묶음은 지식 + 레포 관리(로컬 항목: 지식 레포 · 동기화 · 진단) · 서버 묶음 없음 |
| 사이트(소개 · 설명서 · 로그인 · 처음 설정) | **없다** | 지금 상단 바 그대로. 들어간 사람에게는 오른쪽 위 「내 레포로 ›」 하나 |

- 셸이 메뉴를 **한 번** 그린다 — 레포 ↔ 콘솔을 오가도 메뉴가 다시 마운트되지 않는다(R7 의 「상단 바가 얼굴을 넘어 살아남는다」 를 메뉴가 이어받는다).
- 배지(대기 수)는 `/me` 와 같은 때 읽는 가벼운 값이다 — 메뉴를 그리려고 무거운 요청을 하지 않는다. 레포 화면에서는 App 이 이미 읽은 값을 쓴다.

## 4. 코드에서 바뀌는 자리

| 파일 | 바뀌는 것 |
|---|---|
| `viewer/src/Shell.jsx` | `.shell` 을 가로 둘로 — `<SideNav>` + `<div class="shell__main">(상단 바 + 얼굴)`. 사이트 얼굴은 메뉴 없이 |

| `components/admin/AdminView.jsx` | `admin__menu` 를 지운다 — 탭은 주소로만. `MENU` 는 `SideNav` 의 정의로 옮긴다 |

| `App.jsx` | 세그(문서 · 그래프 · 관리)를 상단 바 포털에서 뺀다 — 메뉴가 그 일을 한다 |
| `styles/app.css` · `tokens.css` | `--nav-w: 232px` · `--nav-w-rail: 56px` · 메뉴 스타일 · 좁은 화면 덮개 |
| 주소 | 새 주소 셋 — `/r/<레포>/manage/curation` · `…/curation/log` · `…/manage/forms`(큐레이터 모델). `/r/<레포>/w`(작업 기록 목록 진입)는 지금 찾기 목록의 「작업문서」 탭을 주소로 꺼낸 것 |
| 설명서(`manual/`) · 사이트 그림(`shots.json`) | 「상단 바의 콘솔」 「관리 › …」 같은 길 안내를 「왼쪽 메뉴 › 서버 › …」 로 · 찍은 판 다시 |

## 5. 하지 않는 것

| | 왜 |
|---|---|
| 메뉴 항목 순서 · 묶음을 사람이 바꾸기 | 메뉴는 넷 묶음 · 열여섯 항목이다. 고칠 이유보다 「사람마다 메뉴가 달라 설명서와 안 맞는」 비용이 크다 |
| 묶음 접기(묶음마다 ▾) | 항목이 적다. 접으면 큐레이션 배지가 숨는다 |
| 사이트 얼굴에 메뉴 | 소개 · 설명서는 로그인 전에도 보는 공개 화면이다 — 메뉴가 들어간 사람의 것을 보이면 D4 와 어긋난다 |
| 문서 화면 들어갈 때 자동 접기 | §2.4 — 사람이 정한 상태를 화면이 바꾸지 않는다 |
