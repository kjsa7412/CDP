# 출장복명 작성 — 화면 내 별도 입력 영역

출장복명 작성을 기안 화면에 이어붙이지 않고 화면 내 별도 입력 영역으로 뺐다.
사진 첨부 영역을 함께 만든다.

세 가지가 한꺼번에 보고됐다. 본인이 출장자가 아닌 경우 입력 폼이 너무 길어
**입력해야 하는지 모르고 넘어간다.** 스크롤이 생겨 아래 항목이 안 보인다.
차량을 안 가져간 경우 사진을 붙이려 했는데 붙일 곳이 없어 복명만 하고
담당자에게 전화했다.

셋 다 "폼이 길다"의 증상이다. 항목을 줄이는 것은 규정상 불가하므로 영역을 나눈다.
