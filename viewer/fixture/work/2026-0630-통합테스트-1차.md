# 통합테스트 1차 — 연구과제 시나리오 타임테이블 확정

연구과제 시나리오 통합테스트 일정을 확정했다. 초안등록 → 접수 → 사전검토 →
연관위심의 → 계획서등록까지 한 흐름으로 묶어 하루에 돌린다.

화면 단위로 쪼개 테스트하면 **상태 전이가 검증되지 않는다.** 실제 사고는 대부분
"이 상태에서 저 버튼이 눌린다"에서 나오지 개별 화면의 입력 검증에서 나오지 않는다.

한 흐름으로 묶으면 앞 단계의 산출물이 뒤 단계의 입력이 되므로 데이터를 인위적으로
만들어 넣을 필요도 없어진다.
