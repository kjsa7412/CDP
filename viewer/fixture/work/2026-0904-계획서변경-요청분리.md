# 계획서변경 요청/확정 분리

계획서변경을 **요청**과 **확정** 두 테이블로 나눴다.

전에는 한 테이블에 상태값으로 섞여 있었다. 요청은 여러 건이 동시에 살아
있을 수 있는데 확정은 하나뿐이라, 한 테이블에 두면 "지금 확정된 것"을
뽑을 때마다 상태 조건을 붙여야 했고 한 번이라도 빠뜨리면 조용히 틀렸다.

| | |
|---|---|
| `rp_plnd_chg_req_mst` | 요청. 여러 건 |
| `rp_plnd_chg_mst` | 확정. 계획서당 하나 |
