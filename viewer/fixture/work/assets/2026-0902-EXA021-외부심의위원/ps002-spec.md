# PS002 외부인원 선택 모달 — 명세

작업 기록 `2026-0902-EXA021-외부심의위원` 의 첨부다.

## 호출 경로

`EXA021` → '외부 심의위원 정보' 그리드 → `선택` 버튼

## 조회 조건

| 항목 | 비고 |
|---|---|
| 성명 | 부분 일치 |
| 전화 | **하이픈 없이** 입력. 저장값도 하이픈 제거 후 비교 |
| 이메일 | 부분 일치 |

검색 항목은 풀 너비를 쓴다. 기존 `gravity:1` 은 세 항목이 좁게 붙어 있었다.

## 왼쪽 — 업무구분 트리

`PS_EXT_EMP_MST.wrk_tp_cd` (코드그룹 `PS130`) 으로 그룹핑한다.

```
연심회 / 평가위원회 / 위원회
```

## 오른쪽 — 인원 그리드

성명 · 소속 · 직급 · 전화 · 이메일. 선택 시 `user_id`, `emp_no` 를 호출 화면으로 넘긴다.

## 미확정

- `PS130` 코드값 전체 목록. 현재 3종만 확인됨
