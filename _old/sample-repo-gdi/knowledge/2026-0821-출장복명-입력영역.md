# 출장복명 작성 — 화면 내 별도 입력 영역 구축

## 무엇이 바뀌었나

출장복명 작성을 기안 화면에 이어붙이지 않고 **화면 내 별도 입력 영역**으로 뺀다.
사진 첨부 영역을 함께 만든다.

## 왜

세 가지가 한꺼번에 보고됐다.

- 본인이 출장자가 아닌 경우 입력 폼이 너무 길어 **입력해야 하는지 모르고 넘어간다**
- 스크롤이 생겨 아래 항목이 보이지 않는다
- 차량을 안 가져간 경우 사진을 붙이려 했는데 붙일 곳이 없어 복명만 하고 담당자에게 전화했다

셋 다 "폼이 길다"의 증상이다. 항목을 줄이는 것은 규정상 불가하므로 **영역을 나눈다.**

## 누구에게 영향

- 출장 담당자 — 복명 작성 위치가 바뀐다
- 전 직원 — 사진 첨부가 가능해진다
