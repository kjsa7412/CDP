# 면접심사의견등록(PSC043) 개편 — 현황/작성 화면 분리

## 무엇이 바뀌었나

PSC043 을 **현황 화면**과 **작성 화면** 둘로 나눴다.

| 화면 | 역할 |
|---|---|
| PSC043 (현황) | 응시자별 면접심사 대상 목록. 진행 상태만 본다 |
| PSC043P (작성) | 대상 1건을 골라 의견을 쓰는 전용 화면 |

작성 화면 레이아웃

```
┌─────────────────────────────────────────────────┐
│ 헤더 : 심사위원(작성자) 정보                      │
├───────────────────────┬─────────────────────────┤
│ 첨부파일 리스트        │                         │
│ ─────────────────     │   의견 입력창            │
│ [PDF 뷰어]            │   (넓게)                 │
│                       │                         │
└───────────────────────┴─────────────────────────┘
```

첨부파일은 PDF 로 넣고, 파일을 선택하면 오른쪽이 아니라 **같은 화면 안의 뷰어**에 뜬다.

출력물 두 종을 함께 구현한다.

- **연대서명 출력물** — 그날 심사위원 서명이 전부 들어가는 한 장
- **개인별 서명 출력물** — 위원 1인당 한 장

기타: 보훈 항목 자동 합계, 주요 경력 항목 제거.

## 왜

심사위원이 화면 하나에서 목록을 보며 의견을 쓰게 했더니 **작업의 연속성이 끊겼다.**
응시자를 바꿀 때마다 그리드에서 행을 다시 찾아야 했고, 첨부파일을 별도 창으로 열면
의견 입력창이 가려졌다.

기존 오프라인 방식은 응시자 서류 묶음을 앞에 놓고 한 명씩 넘기며 쓰는 것이었다.
**그 동작을 화면이 그대로 흉내내야 한다** — 왼쪽에 서류, 오른쪽에 의견.

9월 9일 정규직 심사 전에 한 번 써보고 실제 심사에 쓰겠다는 요구가 있어
개편 범위를 화면 분리와 뷰어까지로 한정했다. 평가 점수 체계는 손대지 않는다.
