# PSC043 면접심사의견등록 — 화면 레이아웃 상세

지식 단위 `2026-0821-면접심사의견-개편` 의 첨부다.

## 현황 화면 (PSC043)

| 영역 | 항목 |
|---|---|
| 조회조건 | 채용공고 · 심사일자 · 분야 |
| 그리드 | 응시번호 · 성명 · 분야 · 의견작성여부 · 작성일 |
| 버튼 | 작성(선택 행) · 출력 |

`의견작성여부` 는 로그인한 심사위원 기준이다. 다른 위원의 작성 여부는 보이지 않는다.

## 작성 화면 (PSC043P)

```
┌─────────────────────────────────────────────────────────────┐
│ 심사위원 : 홍길동 (인사위원회)      심사일 : 2026-09-09      │
│ 응시자   : 20260909-003 김OO       분야   : 연구직           │
├──────────────────────────┬──────────────────────────────────┤
│ 첨부파일                  │                                  │
│  ○ 응시원서.pdf           │   면접 의견                      │
│  ● 자기소개서.pdf         │   ┌────────────────────────────┐ │
│  ○ 경력증명.pdf           │   │                            │ │
│ ────────────────────     │   │                            │ │
│                          │   │                            │ │
│   [ PDF 뷰어 ]           │   │                            │ │
│                          │   └────────────────────────────┘ │
│                          │   보훈 : ☐ 해당  자동합계 : 0    │
└──────────────────────────┴──────────────────────────────────┘
```

- 첨부파일을 선택하면 **같은 화면 안의 뷰어**에 뜬다. 새 창을 열지 않는다
- 의견 입력창은 오른쪽 전체를 쓴다
- `주요 경력` 항목은 제거됐다 (자기소개서에 중복)

## 출력물

| 종류 | 내용 |
|---|---|
| 연대서명 | 그날 심사위원 전원의 서명이 한 장에 들어간다 |
| 개인별 서명 | 위원 1인당 한 장 |

연대서명은 위원 수가 가변이므로 서명란을 동적으로 생성해야 한다.
