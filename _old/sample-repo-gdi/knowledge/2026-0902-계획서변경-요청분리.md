# 계획서변경 요청/확정 분리 — RP_PLND_CHG_REQ_MST 신설

## 무엇이 바뀌었나

계획서변경을 요청과 확정으로 나눴다. 요청은 `RP_PLND_CHG_REQ_MST`,
확정 결과는 기존 `RP_PLND_CHG_MST` 에 남는다.

*(좌표 8개짜리 문서다 — 설계서 §17.4 의 좌표 접기와 프로토콜 §9.3 의
"좌표 10개가 넘으면 작업을 쪼개야 한다는 신호"를 화면에서 확인하기 위한 fixture)*

## 왜

요청 단계에서 반려되면 확정 테이블에 흔적이 남지 않아 **몇 번 반려됐는지 알 수 없었다.**
요청을 별도 테이블로 두면 반려 이력이 그대로 쌓인다.

## 누구에게 영향

- `screen:PLA021` — 요청 저장 대상 테이블이 바뀐다
- `screen:PLA011` — 관리번호 중복확인이 여기서도 필요하다

## 후속 조치

- [ ] PLA011 관리번호 중복확인 누락 — `2026-정-0000` 이 2건 존재. **미해결**
- [ ] PLA021 산출기초가 지워지지 않는 문제
