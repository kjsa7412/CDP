# EXA021 외부 심의위원 정보 — 코드헬프 신설 및 그리드 정비

## 무엇이 바뀌었나

EXA021 '외부 심의위원 정보' 그리드를 정비한다.

- 컬럼 헤더: 성명 · 소속 · 직급 · 전화 · 이메일
- 데이터 출처: `PS_EXT_EMP_MST` (`user_id`, `emp_no`)
- **성명 팝업 코드헬프 신설** — 검색은 성명·전화(하이픈 없이)·이메일
- '추가' 버튼 명칭을 **'선택'** 으로 변경

선택 모달(PS002) 레이아웃

```
┌──────────────────────────────────────────────┐
│ 검색 : 성명 · 전화 · 이메일   (풀 너비)        │
├──────────────────┬───────────────────────────┤
│ 업무구분(PS130)  │ 성명·소속·직급·전화·이메일 │
│  ▾ 연심회        │                           │
│      A1          │                           │
│      A2          │                           │
│  ▾ 평가위원회    │                           │
│  ▾ 위원회        │                           │
└──────────────────┴───────────────────────────┘
```

왼쪽은 `wrk_tp_cd`(PS130) 로 그룹핑한 외부인원 트리다.

## 왜

'추가' 는 신규 등록을 연상시키는데 실제 동작은 기존 외부인원을 **고르는** 것이다.
실제로 없는 사람을 새로 만들려다 문의가 들어왔다.

검색 항목 너비가 `gravity:1` 로 되어 있어 세 항목이 좁게 붙어 있었다.
전화번호는 하이픈 유무가 사람마다 달라 넓은 입력창이 필요하다.
