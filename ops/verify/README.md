# verify — 설계서 §10 을 한 자리에서 돈다

```bash
node ops/verify/run.mjs          # 빠른 것만 (약 30초)
node ops/verify/run.mjs --slow   # 60초 갱신까지
```

번호는 [설계서 §10](../../docs/design/CDP_MCP_설계서_v1.0.md) 의 줄 번호와 같다.

## 왜 있나

단계마다 실측하며 왔지만 **한 번에 돌린 적이 없었다.** 흩어진 확인은 나중에
회귀를 못 잡는다 — 4.3 을 고치다 2단계를 깨도 아무도 모른다.

자동으로 못 도는 것은 **이유를 적고 `–` 로 낸다.** 조용히 빠지면 "통과"와
"안 돌았다"가 구별되지 않는다.

## 무엇을 만들고 무엇을 지우나

`ops/out/verify/` 아래에 판을 새로 깐다(돌 때마다 지우고 다시). 픽스처를
git 레포로 만들어 `save` 가 실제로 커밋하게 하고, 서버를 7377 포트에 띄운다.
**`C:\cdp` 같은 실제 레포는 건드리지 않는다.**
