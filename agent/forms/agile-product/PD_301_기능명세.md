기능의 지금 상태. **섹션 하나가 기능 하나**다 — 가벼운 PRD.

<!-- form:guide -->
**무엇** — 기능마다 **왜(문제) · 누구의 무엇(사용자 스토리) · 언제 됐다고 하나(수용 기준)** ·
성공 지표 · 범위 밖 · 상태 · 기능 플래그.
**언제** — 디스커버리에서 섹션을 세운다. 개발 중 범위가 바뀌면 그 자리에서 고치고, 출시 뒤에는
상태만 바꾼다.
**누가** — 제품 책임자가 세우고, 개발 · 디자인 · QA 가 수용 기준을 같이 다듬는다.

**여기 적지 않는 것**

| | 어디로 |
|---|---|
| 화면의 상태 · 동작 · 접근성 | `화면명세` |
| API 의 계약 · 호환성 | `인터페이스명세` |
| 지표의 계산식 · 출처 이벤트 | `제품지표` — 여기는 이름과 목표만 |
| 플래그의 롤아웃 · 제거 예정일 | `기능플래그` |
| 왜 이 안을 골랐나 · 버린 대안 | 작업 기록(`work/`) — 결정은 거기 남는다 |
| 할 일 쪼개기 · 추정 | 이슈 트래커 |

> **수용 기준은 시험이 될 수 있게 쓴다** — Given/When/Then 한 행이 인수 시험 하나가 된다.
> 「빠르게」 · 「편하게」 는 기준이 아니다.

### 작성지침

| 항목 | 작성방법 | 필수 |
|---|---|:--:|
| 섹션 제목 | `<기능 키> — <기능 이름>`. 키에 공백 · ` - ` 를 쓰지 않는다 | 필수 |
| 그룹 | 제품 영역 · 스쿼드별로 `<!-- 결제 -->` 주석. **제목으로 쓰지 않는다** | 선택 |
| 상태 | 기획 · 개발 중 · 출시 · 정리(플래그까지 지움) · 폐기 | 필수 |
| 제품영역 | `제품영역:<값>` — 찾기 축. 파생되지 않는다 | 선택 |
| 기능 플래그 | 플래그 키만. 롤아웃 · 제거 예정일은 `기능플래그` 에 | 조건 |
| 문제 | 사용자의 말 · 숫자로. **해결책을 적지 않는다** | 필수 |
| 사용자 스토리 | `<누구>로서, <무엇>을 하고 싶다. 그래야 <왜>` | 필수 |
| 수용 기준 | Given/When/Then 표. **한 행이 시험 하나** | 필수 |
| 성공 지표 | `제품지표:<값>` · 목표 · 잴 시점 | 필수 |
| 범위 밖 | 하지 않기로 한 것. 없으면 「없음」 — 비워 두면 안 쓴 것과 구분이 안 된다 | 필수 |
| 그림 | 화면 그림은 `화면명세` 가 디자인 링크로 갖는다. 여기는 글 | 선택 |
| 변경 | `**변경** · 날짜 [작업기록](../../work/…) 무엇이` | 작업 후 필수 |

### 예시 — EX-CHECKOUT — 한 페이지 결제

| | |
|---|---|
| 상태 | **개발 중** |
| 제품영역 | `제품영역:EX-COMMERCE` |
| 담당 | 결제 스쿼드 |
| 기능 플래그 | `checkout_onepage` |
| 관련 좌표 | `화면명세:EX-CART` · `인터페이스:ex-orders` · `데이터모델:ex_order` |

**문제** — 모바일 결제가 배송지 · 결제수단 · 확인 · 완료의 네 화면이라 중간 이탈이 크다.
결제를 시작한 세션의 62% 만 주문을 마친다(2026-09 사용성 시험에서 5명 중 4명이 배송지
화면에서 뒤로 갔다).

**사용자 스토리** — 장바구니를 채운 회원으로서, 한 화면에서 배송지와 결제수단을 고르고 바로
결제하고 싶다. 그래야 이동 중에도 끝낼 수 있다.

**수용 기준**

| # | Given | When | Then |
|--:|---|---|---|
| 1 | 저장된 배송지 · 결제수단이 있는 회원 | 장바구니에서 「결제하기」 를 누른다 | 한 화면에 둘이 미리 골라져 있고 「n원 결제」 단추 하나로 끝난다 |
| 2 | 결제수단이 없는 회원 | 결제 화면에 들어온다 | 결제수단 추가가 **같은 화면에서** 펼쳐진다 |
| 3 | 결제하는 사이 재고가 0 이 된 상품 | 「결제」 를 누른다 | 결제하지 않고 그 상품을 표시해 빼거나 바꾸게 한다 |
| 4 | 첫 요청이 처리 중이다 | 같은 결제를 한 번 더 누른다 | 주문은 하나만 생긴다(멱등 키) |

**성공 지표** — `제품지표:ex_checkout_conversion` 62% → 70%(전체 공개 4주 뒤) · 결제 화면
오류율 0.5% 이하

**범위 밖** — 비회원 결제 · 분할 결제 · 해외 배송. 비회원 결제는 로드맵 Next 로.

> ⚠ **이 섹션은 예시다 — 지우고 시작한다.**

### 예시 — 어휘

```
## 기능명세

- `기능명세:EX-CHECKOUT` — (예시) 한 페이지 결제
  example: 서식 예시 — 지우고 시작한다
  aliases: 원페이지 결제, 결제 개편
```
