<!-- form:head -->
화면의 지금 상태. 섹션 하나가 화면 하나다 — **그림은 디자인 도구가 정본이고,
여기는 그림이 말하지 못하는 것**을 적는다.

<!-- form:guide -->
**무엇** — 화면마다 디자인 링크 · 경로 · **상태(빈 · 로딩 · 오류 · 권한 없음)** · 동작 ·
접근성 · 쓰는 API.
**언제** — 디자인 리뷰를 마치면 세운다. 상태 · 동작 · 문구 규칙이 바뀌면 그 섹션을 고친다.
색 · 간격만 바뀌면 고치지 않는다.
**누가** — 디자이너 · 프론트엔드 개발자.

**여기 적지 않는 것**

| | 어디로 |
|---|---|
| 레이아웃 · 색 · 간격 | 디자인 도구(Figma 등) — `디자인` 칸의 링크로 가리킨다 |
| 왜 이 기능을 만드나 · 수용 기준 | `기능명세` |
| API 의 필드 · 오류 코드 | `인터페이스명세` |
| 컴포넌트 구현 · 스토리 | 코드 레포 |

> **화면 그림을 이 문서에 붙이지 않는다.** 디자인 파일이 바뀌면 붙인 그림은 그날부터
> 거짓이다. 링크를 걸고, 그림이 말하지 못하는 **상태와 동작**만 적는다 — 빈 상태 ·
> 오류 상태는 디자인에서 가장 자주 빠지고 구현이 제멋대로 정하는 자리다.

| 항목 | 작성방법 | 필수 |

| 디자인 | 디자인 도구의 프레임 링크. **그림을 붙이지 않는다** | 필수 |

### 예시 — EX-CART — 장바구니

| | |
|---|---|
| 디자인 | (예시) Figma 「커머스 / 장바구니」 프레임 |
| 경로 | `/cart` · 앱 하단 탭 「장바구니」 |
| 기능 | `기능명세:EX-CHECKOUT` |
| 쓰는 API | `인터페이스:ex-orders`(주문 생성) · 장바구니 조회 · 수량 변경 |
| 권한 | 회원 · 비회원(기기에 저장 — 로그인하면 회원 장바구니와 합친다) |

**상태**

| 상태 | 보이는 것 |
|---|---|
| 빈 | 「장바구니가 비었어요」 · 최근 본 상품 4개 · 「쇼핑 계속하기」 |
| 로딩 | 행 모양 스켈레톤 3줄. 합계는 숨긴다 |
| 오류 | 「불러오지 못했어요」 · 「다시 시도」. 기기에 담긴 상품은 지우지 않는다 |
| 품절 포함 | 그 행을 흐리게 · 「품절」 배지 · 결제 금액에서 빼고 합계를 다시 낸다 |

**동작**

1. 수량을 바꾸면 합계는 바로 바뀌고, 서버 저장은 0.5초 모아서 한 번 한다
2. 「결제하기」 단추에 품절을 뺀 금액을 보인다 — 「32,000원 결제하기」
3. 삭제는 5초 동안 「되돌리기」 토스트를 띄운다
4. 쿠폰 입력은 결제 단추 **위**에 둔다(2026-09-22 조사)

**접근성** — 수량 단추에 「수량 줄이기, 〈상품명〉」 레이블 · 합계가 바뀌면 스크린리더에
알린다(`aria-live`) · 터치 영역 44px 이상 · 글자 대비 4.5:1 — WCAG 2.2 AA

> ⚠ **이 섹션은 예시다 — 지우고 시작한다.**

### 예시 — 어휘

```
## 화면명세

- `화면명세:EX-CART` — (예시) 장바구니
  example: 서식 예시 — 지우고 시작한다
  aliases: 장바구니 화면, 카트
```
