<!-- form:head -->
AI 서비스 구성의 지금 상태. **좌표 넷이 고정이다** — 어느 AI 서비스에나 있는
자리라 값으로 박아 두었다.

<!-- form:guide -->
**무엇** — 이 서비스가 사용자 · 외부 시스템 사이 어디에 서는가(`context`), 요청이 어떤
단계를 거쳐 답이 되는가(`pipeline`), 모델을 어떻게 부르고 막고 바꾸는가(`serving`),
무엇을 남기고 어디서 보는가(`observability`).
**언제** — 설계에서 초안. 단계 · 게이트웨이 · 추적 구성을 바꾸면 그 섹션을 고친다.
**누가** — AI 엔지니어 · 플랫폼 담당.

**여기 적지 않는 것**

| | 어디로 |
|---|---|
| 모델 하나하나의 판 · 한도 · 단가 | `모델카드` |
| 검색 원천 · 쪼개기 · 임베딩 | `지식소스` |
| 도구 하나하나의 권한 · 승인 | `에이전트도구` |
| 지표의 문턱 · 경보 · 대응 | `운영모니터링` |
| 왜 이 구성인가 · 견준 안 | 작업 기록(`work/`) |

> **넷은 서식 예시가 아니다** — 섹션은 두고 안의 (예시) 행만 바꾼다. 늘리거나 줄이려면
> **`_vocab.md` 의 `## 시스템아키텍처` 절과 이 문서를 함께** 고친다.

### 고정 좌표

```
## 시스템아키텍처

- `시스템아키텍처:context` — 시스템 컨텍스트
  aliases: 시스템 경계, 외부 연동, 컨텍스트 다이어그램
- `시스템아키텍처:pipeline` — 처리 흐름(RAG · 에이전트)
  aliases: RAG 흐름, 에이전트 흐름, 처리 파이프라인
- `시스템아키텍처:serving` — 서빙 · 게이트웨이
  aliases: LLM 게이트웨이, 모델 서빙, 대체 모델 전환
- `시스템아키텍처:observability` — 관측 · 추적
  aliases: 관측성, 트레이스, LLMOps
```

### 작성지침

| 항목 | 작성방법 | 필수 |
|---|---|:--:|
| 섹션 | **넷 고정.** 늘리거나 줄이려면 `_vocab.md` 의 `## 시스템아키텍처` 절도 함께 고친다 | 필수 |
| `context` | 상대 · 방향 · 오가는 것. **외부 모델 공급자를 빠뜨리지 않는다** | 필수 |
| `pipeline` | 단계를 **번호 목록**으로. 단계마다 무엇이 걸리면 멈추나 | 필수 |
| `serving` | 게이트웨이 · 대체 · 시간 초과 · 캐시 · 한도. **수치와 판을 적는다** | 필수 |
| `observability` | 무엇을 남기나 · 어디서 보나 · 보존 · 개인정보 처리 | 필수 |
| 그림 | `work/assets/` 에 두고 링크. 흐름은 번호 목록으로 적는다 | 선택 |
| 경과 | `**경과**` 아래 한 줄 `- 날짜 [작업 기록](../work/…) 무엇이` | 반영 때 필수 |

### 예시 — context — 시스템 컨텍스트

| 상대 | 방향 | 무엇이 오가나 | 비고 |
|---|:--:|---|---|
| (예시) 상담원 · 상담 화면 | ↔ | 문의 → 초안 · 근거 링크 | 고객에게는 사람이 보낸다 |
| (예시) 도움말 센터 CMS | → | 문서 원문 · 매일 색인 | `지식소스:ex-help-center` |
| (예시) 주문 시스템 API | ↔ | 주문 조회 · 읽기만 | `에이전트도구:ex_lookup_order` |
| (예시) 모델 공급자 X | ↔ | 프롬프트 → 생성 | 게이트웨이를 거친다(`serving`) |

> ⚠ **예시 행이다 — 지우고 시작한다.**

### 예시 — pipeline — 처리 흐름

(예시) 상담 답변 초안 요청 하나 —

1. **입력 검사** — 개인정보 마스킹 · 길이 제한 · 인젝션 의심 문구 표시
2. **검색** — 질문 임베딩 → 도움말 색인 상위 8 → 재순위 상위 4 · 사용자 권한으로 거른다
3. **도구** — 주문번호가 있으면 주문 조회 한 번 · 실패해도 계속
4. **생성** — `프롬프트:ex-support-answer` · 근거 인용 강제
5. **출력 검사** — 근거 없는 문장 · 개인정보 재노출 · 금칙 표현 → 걸리면 초안을 내지 않는다
6. **표시** — 「AI 초안」 표지 · 근거 링크 · 확신 낮음 표시

> ⚠ **예시 행이다 — 지우고 시작한다.**

### 예시 — serving — 서빙 · 게이트웨이

| 구성 | 무엇 | 값 |
|---|---|---|
| (예시) LLM 게이트웨이 | 공급자 호출을 한 곳으로 — 키 · 한도 · 재시도 · 기록 | 사내 게이트웨이 1.4 |
| (예시) 기본 · 대체 모델 | 오류 · 시간 초과 때 한 번 바꾼다 | `모델카드:ex-answer-llm` 의 대체 칸 |
| (예시) 시간 초과 | 단계별 상한 | 검색 1초 · 생성 8초 |
| (예시) 캐시 | 같은 질문 + 같은 근거면 재사용 · 프롬프트 판이 바뀌면 비운다 | 24시간 |
| (예시) 한도 | 넘으면 초안 없이 도움말 목록만 | 분당 600 요청 · 일 토큰 상한 |

> ⚠ **예시 행이다 — 지우고 시작한다.**

### 예시 — observability — 관측 · 추적

| 무엇을 남기나 | 어디로 | 보존 |
|---|---|---|
| (예시) 요청 추적(trace) — 단계별 입력 · 출력 · 지연 · 토큰 · 판 | 추적 도구 | 30일 · 개인정보는 가린 채 |
| (예시) 상담원 피드백 — 채택 · 고친 차이 · 신고 | 데이터 웨어하우스 | 1년 |
| (예시) 비용 · 지연 지표 | 지표 대시보드 | 13개월 |

**판을 추적에 싣는다** — 모델 · 프롬프트 · 색인의 판이 요청마다 찍혀야 품질이 움직였을 때
무엇이 바뀌었는지 가를 수 있다.

> ⚠ **예시 행이다 — 지우고 시작한다.**
