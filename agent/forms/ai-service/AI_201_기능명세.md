AI 기능의 지금 상태. 섹션 하나가 AI 기능 하나다.

<!-- form:guide -->
**무엇** — AI 기능마다 **무엇을 받아 무엇을 내고, 얼마나 좋아야 하며, 실패하면 어떻게 하는가.**
입력 · 출력 · 품질 기준 · 실패 시 대체 · 사람 검토 · 비용 · 지연 예산.
**언제** — 기획에서 만들고, 기준이나 흐름이 바뀌면 그 섹션을 고친다.
**누가** — 기능 담당 제품 책임자 · AI 엔지니어.

**여기 적지 않는 것**

| | 어디로 |
|---|---|
| 프롬프트 · 출력 형식의 세부 | `프롬프트명세` |
| 품질을 재는 사례와 문턱 | `평가셋` — 여기는 기준의 **뜻**, 거기는 **숫자와 사례** |
| 모델의 한도 · 단가 | `모델카드` |
| 서비스 전체의 목적 · 쓰지 않는 경우 | `서비스개요` |
| 왜 이 기능을 이렇게 정했나 | 작업 기록(`work/`) |

> **품질 기준은 평가셋으로 잰다.** 「정확해야 한다」 는 기준이 아니다 — 어느 평가셋의
> 어느 지표가 몇 이상인지가 기준이다. 여기서는 그 평가셋 섹션을 좌표로 가리킨다.

### 작성지침

| 항목 | 작성방법 | 필수 |
|---|---|:--:|
| 섹션 제목 | `<기능ID> — <기능명>` | 필수 |
| 상태 | 기획 · 시범 · 운영 · 중단 | 필수 |
| 연결 칸 | 흐름 · 프롬프트 · 모델 · 지식 · 도구 · 평가를 **좌표로** 적는다. 안 쓰면 「없음」 | 필수 |
| 입력 · 출력 | 개인정보를 어디서 가리나 · AI 결과물임을 어떻게 표시하나 | 필수 |
| 품질 기준 | 지표 · 문턱 · 재는 평가셋. **뜻만 있는 기준을 쓰지 않는다** | 필수 |
| 실패 시 대체 | 모델이 틀리거나 멈출 때 사용자가 보는 것 | 필수 |
| 사람 검토 | 누가 언제 보나. 없으면 왜 없는지 | 필수 |
| 예산 | 요청당 비용 · 지연 p95 | 필수 |
| 범위 밖 | 이 기능이 하지 않는 것 | 선택 |
| 경과 | `**경과**` 아래 한 줄 `- 날짜 [작업 기록](../work/…) 무엇이` | 반영 때 필수 |

<!-- form:example -->
### 예시 — EX-SUPPORT-ANSWER — 상담 답변 초안

| | |
|---|---|
| 상태 | 시범 — 상담원 20명 |
| 기능 플래그 | `support_answer_draft` |
| 사용자 | 상담원. 고객은 AI 를 직접 만나지 않는다 |
| 흐름 | `시스템아키텍처:pipeline` — 입력 검사 → 검색 → 생성 → 출력 검사 |
| 프롬프트 | `프롬프트:ex-support-answer` |
| 모델 | `모델카드:ex-answer-llm` |
| 지식 | `지식소스:ex-help-center` |
| 도구 | `에이전트도구:ex_lookup_order` — 읽기만 |
| 평가 | `평가셋:ex-support-golden` |

**입력** — 고객 문의 원문 · 주문번호(있으면) · 상담 채널. 전화번호 · 주소는 모델에 넣기 전에 가린다.

**출력** — 답변 초안 하나 · 근거로 쓴 도움말 문서 링크 · 확신 낮음 표시. 상담 화면에
「AI 초안」 표지를 달아 보인다.

**품질 기준**

| 무엇 | 기준 | 어디서 재나 |
|---|---|---|
| 근거 충실 — 안내가 근거 문서에 있다 | 0.90 이상 | `평가셋:ex-support-golden` |
| 정답 일치 — 사람 채점 | 4.0 / 5 이상 | 〃 |
| 개인정보 노출 | 0건 | 〃 · 운영 표본 검수 |

**실패 시 대체** — 검색 결과가 없거나 근거 점수가 낮으면 초안을 내지 않고 「관련 도움말」
목록만 보인다. 모델 오류 · 시간 초과면 대체 모델로 한 번, 그래도 실패하면 빈 칸.

**사람 검토** — 모든 초안은 상담원이 고쳐 보낸다. 고친 차이가 피드백으로 남는다.

**예산** — 문의당 비용 30원 이하 · 첫 글자 p95 2초 · 전체 p95 6초.

**범위 밖** — 환불 · 보상 결정 · 분쟁 문의.

> ⚠ **이 섹션은 예시다 — 지우고 시작한다.**

### 예시 — 어휘

```
## 기능명세

- `기능명세:EX-SUPPORT-ANSWER` — (예시) 상담 답변 초안
  example: 서식 예시 — 지우고 시작한다
  aliases: 답변 초안, 상담 보조
```
