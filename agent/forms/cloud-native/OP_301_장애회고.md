<!-- form:head -->
장애 회고의 지금 상태. **섹션 하나가 장애 하나다** — 영향 · 타임라인 · 원인 · 잘된 것, 그리고
**후속 조치가 닫혔나.** 비난 없는 회고다 — 누가 틀렸나가 아니라 무엇이 그것을 쉽게 만들었나를 쓴다.

<!-- form:guide -->
**무엇** — 등급 · 기간 · 영향 · 태운 오류 예산 · 타임라인 · 원인(기여 요인) · 잘된 것 · 운이 좋았던 것 · **후속 조치와 상태.**
**언제** — 회고 회의 뒤 바로 쓴다. 후속 조치를 진행하거나 닫는 작업 기록이 이 좌표를 달고, 그때마다 표의 상태를 고친다.
**누가** — 사건 지휘자가 쓰고, 조치 담당이 상태를 고친다.

**여기 적지 않는 것**

| | 어디로 |
|---|---|
| 장애 중 대화 · 원본 로그 | 장애 채널 · 장애 관리 도구 — 타임라인에는 요약만 |
| 장애 등급 · 선언 · 역할 | `온콜체계` |
| 고친 대응 절차 | `런북` |
| 태운 예산 · 목표 | `서비스수준` |
| 원인을 고친 변경의 「왜」 | 작업 기록(`work/`) — 그 기록이 이 좌표를 단다 |

> **회고는 사건이지만 후속 조치가 닫힐 때까지 살아 있다.** 원인을 고치는 작업 기록이 `touches:` 에 이 장애의
> 좌표를 달면 이 섹션의 「후속 조치」 를 고칠 때까지 커밋이 막힌다 — 「회고를 쓰고 잊는다」 를 파생이 막는다.
>
> **사람 이름을 원인에 쓰지 않는다.** 「누가 설정을 잘못 넣었다」 가 아니라 「그 설정이 시험 없이 운영에 갈 수 있었다」 다.

| 등급 · 상태 | 등급은 `온콜체계` 의 정의. 상태는 **후속 조치 진행중 · 닫힘** 둘 중 하나 | 필수 |

### 예시 — EX-INC-001 — 결제 승인 지연

| | |
|---|---|
| 등급 · 상태 | SEV2 · **후속 조치 진행중** — 조치가 다 닫히면 「닫힘」 |
| 기간 | 2026-09-18 20:05 ~ 21:10 KST(65분) · 감지 20:12 |
| 영향 | 결제 요청의 18% 가 10초 넘게 걸리거나 실패 · 주문 약 1,200건 지연 · 이중 결제 0건 |
| 서비스수준 | `서비스수준:ex-checkout-availability` — 30일 예산의 45% |
| 관련 서비스 | `서비스명세:ex-order-api` · 결제 서비스(payment-api) |
| 역할 | 사건 지휘 커머스 팀 리드 · 기록 SRE 당번 · 소통 고객 지원 |

**타임라인** — 쌓는다.

- `20:05` 결제 서비스 배포 100% — DB 커넥션 풀 크기를 줄인 설정이 같이 나갔다
- `20:12` `런북:EX-ORDER-5XX` 호출 · 당번 확인
- `20:25` 결제 서비스 지연 확인 · 결제 팀 당번 호출
- `20:41` SEV2 선언 · 상태 페이지 공지
- `20:52` 결제 서비스 되돌림
- `21:10` 지표 정상 · 해제

**원인 — 기여 요인**

- 카나리 5% 에서는 커넥션 풀이 남아 문제가 드러나지 않았다 — 분석이 p99 지연 · 연결 대기를 보지 않았다
- 주문 → 결제 호출의 시간 초과가 10초라 주문 서비스 스레드가 쌓였다
- 설정 변경이 코드 변경과 같은 PR 에 묻혀 리뷰에서 보이지 않았다

**잘된 것** — 경보가 7분 안에 울렸다 · 아웃박스 덕에 이벤트 유실이 없었다 · 멱등 키로 이중 결제가 없었다.
**운이 좋았던 것** — 기획전 전날 저녁이었다.

**후속 조치**

| 조치 | 담당 | 기한 | 상태 | 관련 좌표 |
|---|---|---|---|---|
| 카나리 분석에 p99 지연 · 연결 대기 추가 | 플랫폼 팀 | 2026-09-30 | 완료 | — (배포파이프라인) |
| 결제 호출 시간 초과 10초 → 3초 · 서킷 브레이커 | 커머스 팀 | 2026-10-09 | 진행중 | `서비스명세:ex-order-api` |
| 런북에 「결제 대기」 플래그 단계 추가 | 커머스 팀 | 2026-10-16 | 열림 | `런북:EX-ORDER-5XX` |
| 풀 · 시간 초과 설정 변경은 PR 을 따로 | 결제 팀 | 2026-10-30 | 열림 | — |
