<!-- form:head -->
데이터저장소의 지금 상태. **섹션 하나가 DB · 캐시 · 버킷 하나다** — 누가 소유하고, 무엇이 들어 있고,
잃으면 어디까지 되살리나.

<!-- form:guide -->
**무엇** — 종류와 엔진 판 · 소유 서비스 · 환경 · 정본 위치 · 크기 · 백업 · **RPO · RTO** · 보존 · 개인정보 · 접근.
**언제** — 저장소를 만들 때 세운다. 엔진 판을 올리거나 인스턴스를 바꾸거나 보존 · 접근을 바꾸면 고친다.
**누가** — 소유 서비스의 담당 팀. 백업 · 복구 리허설은 플랫폼 팀과 같이.

**여기 적지 않는 것**

| | 어디로 |
|---|---|
| 인스턴스 · 파라미터 · 복제 설정 값 | 코드 레포의 IaC(Terraform) — `정본 위치` 로 가리킨다 |
| 테이블 · 컬럼 · 인덱스 | 코드 레포의 마이그레이션(Flyway · Liquibase 같은 것) |
| 소유 서비스의 책임 · 의존 | `서비스명세` |
| 환경별 계정 · 네트워크 | `인프라구성` |
| 암호화 · 접근 통제의 공통 기준 | `보안기준` |
| 저장 비용 | `비용현황` |
| 왜 이 엔진인가 · 왜 나눴나 | 작업 기록(`work/`) |

> **저장소 하나에 주인은 하나다.** 다른 서비스가 그 DB 를 직접 읽기 시작하면 스키마가 계약이 되고,
> 마이그레이션 하나가 남의 서비스를 깨뜨린다. 남은 API · 이벤트로 받는다.

### 작성지침

| 항목 | 작성방법 | 필수 |
|---|---|:--:|
| 섹션 제목 | `<저장소 키> — <저장소 이름>` | 필수 |
| 종류 · 엔진 | 관계형 · 키값 · 문서 · 객체 · 검색 + 엔진과 **판** | 필수 |
| 소유 서비스 | `서비스명세:` 좌표 **하나** | 필수 |
| 환경 | `인프라:` 좌표마다 구성이 다르면 그 차이 | 필수 |
| 정본 위치 | IaC · 마이그레이션 경로. **설정 값을 옮기지 않는다** | 필수 |
| 백업 · RPO · RTO | 수치로. **리허설로 잰 값**이 아니면 목표라고 적는다 | 필수 |
| 보존 · 개인정보 | 얼마나 두나 · 근거 · 무엇이 개인정보인가 · 어떻게 지키나 | 필수 |
| 접근 | 서비스 · 사람 · 비상 접근을 나눠 | 필수 |
| 마지막 복구 리허설 | 날짜 · 걸린 시간 · 걸린 것. 캐시처럼 잃어도 되는 것은 「잃어도 된다」 고 적는다 | 필수 |
| 경과 | `**경과**` 아래 한 줄 `- 날짜 [작업 기록](../work/…) 무엇이` | 반영 때 필수 |

### 예시 — ex-order-db — 주문 DB

| | |
|---|---|
| 종류 · 엔진 | 관계형 · PostgreSQL 16 · 관리형 서비스 |
| 소유 서비스 | `서비스명세:ex-order-api` — **이 서비스만 쓴다** |
| 환경 | `인프라:prod` 다중 AZ · 읽기 복제 1 · `인프라:stg` 단일 · `인프라:dev` 컨테이너 |
| 정본 위치 | (예시) 인스턴스 `infra/modules/order-db/` (Terraform) · 스키마 `order-api` 레포 `db/migration/` |
| 크기 · 증가 | (예시) 120 GiB · 월 6 GiB |
| 백업 | 자동 스냅숏 매일 · 보관 35일 · 시점 복구(PITR) 켬 · 다른 리전 사본 매일 |
| RPO · RTO | 5분 · 1시간 — 분기마다 stg 에서 복구 리허설로 잰다 |
| 보존 | 주문 5년(거래 기록 · 법무 확인) · 지나면 익명화 배치 |
| 개인정보 | 이름 · 연락처 · 주소 — 컬럼 암호화 · 로그에 남기지 않는다 |
| 접근 | 서비스 계정(IAM DB 인증) · 사람은 읽기 전용 역할 · 쓰기는 break-glass 승인 · 감사 기록 |

**마지막 복구 리허설** — (예시) 2026-09-12 · 스냅숏 + PITR 로 48분 · 걸린 것: 복구한 인스턴스의 파라미터 그룹을 손으로 붙였다.

> ⚠ **이 섹션은 예시다 — 지우고 시작한다.**

### 예시 — 어휘

```
## 데이터저장소

- `데이터저장소:ex-order-db` — (예시) 주문 DB
  example: 서식 예시 — 지우고 시작한다
  aliases: 주문 데이터베이스, orders DB
```
