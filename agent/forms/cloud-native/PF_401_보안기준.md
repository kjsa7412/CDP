<!-- form:head -->
모든 서비스 · 환경이 지키는 보안 규칙. **누가 무엇에 접근하고, 비밀을 어디에 두고, 무엇을 믿고
내보내며, 취약점을 언제까지 고치나.**

<!-- form:guide -->
**무엇** — 신원과 권한(IAM) · 비밀 · 공급망(SBOM · 서명) · 이미지 검사 · **취약점 조치 기한** · 런타임 · 기록.
**언제** — 플랫폼을 세울 때 쓰고, 감사 지적 · 사고 · 새 규제가 생기면 고친다.
**누가** — 보안 담당이 쓰고, 플랫폼 팀이 게이트 · 정책으로 강제한다.

**여기 적지 않는 것**

| | 어디로 |
|---|---|
| 신뢰 경계와 무엇이 지키나 | `시스템아키텍처` 의 `시스템아키텍처:security` |
| 환경별 접근 방법 | `인프라구성` |
| 규칙이 파이프라인 어디서 막히나 | `배포파이프라인` |
| 입장 정책 · IAM 정책 원문 | 코드 레포(정책 · IaC) — 이 문서는 규칙과 이유다 |
| 보안 사고의 대응 · 회고 | `온콜체계` · `장애회고` |
| 예외 승인 · 왜 이 기준인가 | 작업 기록(`work/`) — 예외는 만료일과 같이 |

> **규칙은 사람이 아니라 게이트가 지킨다.** 이 문서의 규칙마다 「무엇이 강제하나」 가 있어야 한다 —
> 없으면 권고다. 권고는 그렇게 적는다.

### 작성지침

| 항목 | 작성방법 | 필수 |
|---|---|:--:|
| 규칙 | 한 행에 하나. **「무엇이 강제하나」 가 빈 규칙은 권고**라고 적는다 | 필수 |
| 취약점 기한 | 심각도 · 노출 여부 · 기한 · 예외 경로 | 필수 |
| 예외 | 표에 적지 않는다 — 작업 기록에 만료일과 같이 | 필수 |
| 근거 | 법규 · 인증 기준(ISMS-P 같은 것)이 있으면 규칙 옆에 이름만 | 선택 |
| 변경 | 문서 맨 아래에 `**변경** · 날짜 [작업기록](../../work/…) 무엇이` 를 쌓는다 | 변경 시 필수 |

<!-- form:example -->
### 예시 — 신원과 권한

| 규칙 | 무엇이 강제하나 |
|---|---|
| (예시) 사람은 SSO · 다중 인증 · 단기 자격만 — 장기 액세스 키를 만들지 않는다 | 클라우드 조직 정책 |
| (예시) 워크로드는 워크로드 아이덴티티 — 서비스마다 역할 하나 · 최소 권한 | IaC 모듈 · 분기마다 쓰지 않은 권한 검토 |
| (예시) 운영 쓰기 권한은 break-glass — 승인 · 1시간 · 기록 | 접근 요청 도구 |

### 예시 — 비밀

| 규칙 | 무엇이 강제하나 |
|---|---|
| (예시) 비밀은 비밀 관리자에만 — 레포 · 이미지 · 환경 변수 파일에 두지 않는다 | 커밋 전 · CI 비밀 탐지 |
| (예시) 클러스터에는 동기화로 들인다(External Secrets 같은 것) | 입장 정책 |
| (예시) DB 자격 90일 순환 · 새 판이 돌면 옛 판 폐기 | 비밀 관리자 순환 설정 |

### 예시 — 공급망

| 규칙 | 무엇이 강제하나 |
|---|---|
| (예시) 이미지마다 SBOM(SPDX · CycloneDX)과 빌드 출처 증명 | CI |
| (예시) 서명한 이미지만 운영에 — 서명은 CI 의 신원으로(Sigstore 같은 것) | 입장 정책 |
| (예시) 베이스 이미지는 승인 목록에서 · 최소 이미지 | 입장 정책 · 리뷰 |

### 예시 — 취약점 조치 기한

| 심각도 | 기한 | 예외 |
|---|---|---|
| (예시) Critical — 인터넷에 노출 | 72시간 | 없음 — 못 고치면 완화(차단 · 끄기) |
| (예시) Critical · High | 7일 · 30일 | 작업 기록 + 만료일 + 보안 담당 승인 |
| (예시) Medium · Low | 90일 · 정기 갱신 때 | 팀 판단 |

**런타임 · 기록** — (예시) 파드 보안 표준 restricted · 루트 금지 · 읽기 전용 파일 시스템 ·
네트워크 정책 기본 거부 · 클라우드 감사 로그와 쿠버네티스 감사 로그 1년.

> ⚠ **예시 행이다 — 지우고 시작한다.** 절 제목은 두고 내용을 팀의 것으로 바꾼다.
