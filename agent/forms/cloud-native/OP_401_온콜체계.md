<!-- form:head -->
장애에 어떻게 대응하는 조직인가. **등급 · 당번 · 전파 · 에스컬레이션 · 선언과 종료** — 경보 하나의
대응은 런북이 갖고, 여기는 모든 장애에 같은 틀이다.

<!-- form:guide -->
**무엇** — 장애 등급의 정의 · 당번 순환 · 호출 전파와 응답 시간 · 에스컬레이션 · 장애 선언과 역할 · 종료와 회고 기한 · 경보 위생.
**언제** — 첫 호출 경보를 만들기 전에 세우고, 등급이나 당번 방식을 바꾸면 고친다.
**누가** — SRE 리드가 쓰고, 서비스 팀 리드가 같이 정한다.

**여기 적지 않는 것**

| | 어디로 |
|---|---|
| 경보 하나하나의 대응 | `런북` |
| 경보의 기준이 되는 목표 | `서비스수준` |
| 지난 장애의 경과 · 후속 조치 | `장애회고` |
| 서비스별 담당 팀 · 호출 대상 | `서비스명세` |
| 당번표 · 호출 규칙 자체 | 호출 도구 — 그것이 정본이다 |
| 왜 이 등급 · 이 순환인가 | 작업 기록(`work/`) |

> **당번은 지속 가능해야 한다.** 한 사람이 한 주에 밤 호출을 두 번 넘게 받으면 경보가 틀렸다 —
> 사람을 늘리기 전에 경보를 고친다.

### 골격

| # | 절 |
|--:|---|
| 1 | 장애 등급 |
| 2 | 당번 |
| 3 | 전파와 에스컬레이션 |
| 4 | 선언과 종료 |

### 작성지침

| 항목 | 작성방법 | 필수 |
|---|---|:--:|
| 장애 등급 | 등급마다 **사용자가 겪는 것**으로 기준을 쓴다 — 내부 지표가 아니다 | 필수 |
| 당번 | 순환 · 인수인계 · 보상. 당번표 자체는 호출 도구에 | 필수 |
| 전파 · 에스컬레이션 | 단계 · 누구 · 몇 분 | 필수 |
| 선언과 종료 | 역할 · 종료 기준 · 회고 기한 | 필수 |
| 근거 | 다른 문서에 있는 것은 **옮겨 적지 말고 이름으로 가리킨다** | 필수 |
| 경과 | 문서 맨 아래에 `**경과**` 아래 한 줄 `- 날짜 [작업 기록](../work/…) 무엇이` 를 쌓는다 | 반영 때 필수 |

### 예시 — 장애 등급

| 등급 | 기준 | 선언 · 알림 | 회고 |
|---|---|---|---|
| (예시) SEV1 | 핵심 여정(결제 · 로그인)이 대부분 안 된다 · 데이터 유실 · 보안 사고 | 즉시 선언 · 경영진 · 상태 페이지 | 필수 · 5영업일 |
| (예시) SEV2 | 핵심 여정 일부 실패 · 오류 예산 20% 넘게 탐 | 15분 안 선언 · 관련 팀 · 상태 페이지 | 필수 · 5영업일 |
| (예시) SEV3 | 우회가 있는 기능 저하 · 내부 도구 | 팀 채널 | 팀 판단 |
| (예시) SEV4 | 사용자 영향 없음 — 근접 사고 | 티켓 | 선택 — 배울 것이 있으면 |

### 예시 — 당번

- (예시) **1차 · 2차** — 서비스 팀마다 1주 순환 · 월요일 10시 인수인계(열린 건 · 낌새 · 진행 중 배포)
- (예시) **플랫폼 당번** — 클러스터 · 네트워크 · 관측 · 브로커
- (예시) **보상** — 밤 · 휴일 호출은 다음 날 오전 휴식 · 수당은 사내 기준

### 예시 — 전파와 에스컬레이션

| 단계 | 누구 | 응답 |
|---|---|---|
| (예시) 호출 | 1차 당번 | 5분 안 확인 |
| (예시) 미확인 · 미해결 | 2차 당번 | 15분 |
| (예시) SEV1 · SEV2 | 팀 리드 · 플랫폼 당번 · 보안(보안 사고면) | 선언 즉시 |

### 예시 — 선언과 종료

1. **선언** — 등급을 붙이고 장애 채널을 연다. 등급은 낮추기보다 높였다 낮추는 편이 싸다
2. **역할** — 사건 지휘(결정) · 소통(상태 페이지 · 고객 지원) · 기록(타임라인). SEV1 은 셋을 다른 사람이
3. **완화** — 원인보다 완화가 먼저 — 되돌리기 · 플래그 · 트래픽 돌리기
4. **종료** — 지표가 30분 정상이면 해제 · 상태 페이지 마감
5. **회고** — 등급의 기한 안에 `장애회고` 에 섹션을 세운다

**경보 위생** — 호출은 사람이 지금 움직여야 할 때만. 모든 호출 경보에 런북이 있다. 주 1회 지난주 호출을
보고 할 일이 없었던 경보는 티켓으로 내리거나 지운다.

> ⚠ **예시 행이다 — 지우고 시작한다.** 절 제목은 두고 내용을 팀의 것으로 바꾼다.
