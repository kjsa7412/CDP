<!-- form:head -->
코드가 운영까지 가는 길. **무엇이 막고 · 누가 승인하고 · 어떻게 조금씩 내보내고 · 어떻게 되돌리나.**

<!-- form:guide -->
**무엇** — CI 게이트 · GitOps 동기화 · 승인 · 점진 배포(카나리 · 블루그린) · 되돌리기 · 배포 동결.
**언제** — 첫 서비스를 내보내기 전에 세우고, 게이트나 배포 방식을 바꾸면 고친다.
**누가** — 플랫폼 팀이 쓰고, 서비스 팀 테크 리드가 본다.

**여기 적지 않는 것**

| | 어디로 |
|---|---|
| 파이프라인 정의 · 롤아웃 설정 자체 | 코드 레포(CI 워크플로 · GitOps 레포) — 이 문서는 규칙과 이유다 |
| 환경별 클러스터 · 동기화 경로 | `인프라구성` |
| 서명 · SBOM · 취약점 기준 | `보안기준` |
| 카나리 분석이 보는 목표 | `서비스수준` |
| 배포 뒤 경보가 울렸을 때 | `런북` |
| 게이트를 왜 바꿨나 | 작업 기록(`work/`) |

> **원하는 상태는 Git 에 있다.** 클러스터에 손으로 `kubectl apply` 하지 않는다 — 동기화 도구가 되돌리고,
> 남은 것은 드리프트 경보다. 되돌리기도 Git 의 되돌리기다.

### 작성지침

| 항목 | 작성방법 | 필수 |
|---|---|:--:|
| 흐름 | PR 에서 운영까지 **번호 목록**으로. 사람이 끼는 자리를 굵게 | 필수 |
| 게이트 | 어디서 · 무엇을 막나. **막지 않는 검사는 게이트가 아니다** — 경고만이면 그렇게 적는다 | 필수 |
| 점진 배포 | 기본 방식과 예외. 분석 기준은 수치로 | 필수 |
| 되돌리기 · 동결 | 누가 · 무엇으로 · 얼마나 걸리나 | 필수 |
| 근거 | 다른 문서에 있는 것은 **옮겨 적지 말고 이름으로 가리킨다** | 필수 |
| 변경 | 문서 맨 아래에 `**변경** · 날짜 [작업기록](../../work/…) 무엇이` 를 쌓는다 | 변경 시 필수 |

### 예시 — 흐름

(예시) 서비스 하나가 운영까지 —

1. **PR** — 빌드 · 단위 시험 · 정적 분석 · 계약 시험 · 비밀 탐지
2. **머지** — 이미지 빌드 · 태그는 커밋 SHA(불변) · SBOM · 취약점 검사 · 서명
3. **dev · stg** — GitOps 레포에 이미지 태그를 올리는 PR 을 봇이 열고 자동 머지 → 동기화 → 스모크 시험
4. **prod** — 같은 PR 을 사람이 승인(1등급 서비스는 담당 팀 외 1명) → 카나리
5. **카나리** — 5% → 25% → 50% → 100% · 단계마다 10분 분석 · 기준을 넘으면 자동 중단 · 되돌림

### 예시 — 게이트

| 게이트 | 어디서 | 막는 기준 |
|---|---|---|
| (예시) 시험 · 정적 분석 | PR | 실패 하나라도 |
| (예시) 깨지는 API · 스키마 변경 | PR | OpenAPI diff · `buf breaking` · 레지스트리 호환성 검사 실패 |
| (예시) 취약점 | 머지 뒤 이미지 | `보안기준` 의 기한을 넘긴 Critical · High |
| (예시) 서명 · 정책 | 클러스터 입장 | 서명 없는 이미지 · 리소스 요청 없음 · 루트 실행 |
| (예시) 카나리 분석 | prod | 오류율 기준선 + 1%p · p99 지연 1.5배 · SLO 번레이트 |

### 예시 — 점진 배포

| 방식 | 언제 | 주의 |
|---|---|---|
| 카나리 | 기본 — 트래픽을 나눠도 되는 무상태 서비스 | 카나리 비율이 작으면 연결 풀 · 캐시 문제가 늦게 드러난다 |
| 블루그린 | 판 둘이 같이 돌면 안 될 때 · 빠른 전환이 필요할 때 | 자원이 두 배 · 전환 전에 그린을 데운다 |
| 기능 플래그 | 코드는 내보내고 기능은 나중에 켤 때 | 플래그도 배포다 — 켜는 것을 작업 기록에 남긴다 |

**DB 스키마는 확장 → 이전 → 축소 세 번에 나눈다** — 새 판과 옛 판이 같은 스키마 위에서 같이 돌 수 있어야 되돌릴 수 있다.

### 예시 — 되돌리기 · 동결

- **되돌리기** — GitOps 레포의 이미지 태그 커밋을 되돌린다. 데이터를 바꾼 배포는 되돌릴 수 없다 — 앞으로 고친다
- **오류 예산 동결** — 예산이 바닥난 서비스는 기능 배포를 멈춘다. 기준은 `서비스수준` 의 오류 예산 정책
- **행사 동결** — (예시) 대형 할인 행사 전 48시간 · 보안 수정만

> ⚠ **예시 행이다 — 지우고 시작한다.** 절 제목은 두고 내용을 팀의 것으로 바꾼다.
