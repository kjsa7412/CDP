<!-- form:head -->
화면의 지금 상태. 섹션 하나가 프로그램(화면) 하나다.

<!-- form:guide -->
**무엇** — 화면마다 **무엇이 보이고 무엇을 누를 수 있는가**를 적는다.
조회 조건 · 목록 컬럼 · 버튼 · 탭 구성.
**언제** — 설계에서 만들고, 화면이 바뀔 때마다 그 섹션을 고친다.
**누가** — 화면설계 담당.

**여기 적지 않는 것**

| | 어디로 |
|---|---|
| 그 화면이 어떤 테이블을 읽고 쓰는가 | `프로그램사양서` — **같은 좌표 값의 구현면** |
| 업무 흐름상 앞뒤 | `프로세스정의서` |
| 화면 목록 · 권한 집계 | `프로그램목록` |

> **`화면설계서:` 과 `프로그램사양서:` 는 같은 ID 공간을 쓴다.** `EXA010` 한 값이 여기서는
> 설계면, 프로그램사양서에서는 구현면이다. 등록부는 패턴 하나에 문서 하나라
> 충돌하지 않는다.
>
> **탭은 좌표가 아니다.** 원본에 `TAB ID` 컬럼이 있었지만 200행 전부 비어
> 있었다. 탭은 섹션 안에서 소제목 없이 나눈다.

### 작성지침

| 항목 | 작성방법 | 필수 |
|---|---|:--:|
| 섹션 제목 | `<프로그램ID> — <화면명>` | 필수 |
| 업무구분 · 분류 | 프로그램목록과 같은 값을 쓴다 | 필수 |
| 권한 | `<역할>(<할 수 있는 것>)` | 필수 |
| AS-IS | 이관 중에만. 끝나면 그 줄을 지운다 | 선택 |
| 조회 조건 | 코드 조건은 `코드정의서:<구분>` 을 덧붙인다 | 필수 |
| 목록 | 컬럼과 **특별한 동작**(이동 · 색 · 숨김) | 필수 |
| 버튼 | 권한이 갈리면 함께 적는다 | 필수 |
| 탭 | 없으면 "없음" 이라고 적는다 — 비워 두면 안 쓴 것과 구분이 안 된다 | 필수 |
| 그림 | `work/assets/` 에 두고 링크. **본문에 붙이지 않는다** | 선택 |
| 변경 | `**변경** · 날짜 [작업기록](../../work/…) 무엇이` | 작업 후 필수 |

### 예시 — EXA010 — 과제접수목록

| | |
|---|---|
| 업무구분 | EX 연구과제수행 |
| 분류 | EXA 과제접수 |
| 권한 | 전체(조회) · 과제 PM(등록) |
| AS-IS | `EXA0100M` — **이관이 끝나면 이 줄을 지운다** |

**조회 조건** — 과제년도 · 연구분류(`코드정의서:EX010`) · 진행상태 · 과제명

**목록**

| 컬럼 | 비고 |
|---|---|
| 과제명 | 누르면 상세(`화면설계서:EXA011`)로 |
| 연구분류 | 코드명 표시 |
| 진행상태 | `임시등록` 은 **회색으로** 구분 |
| 접수일자 | |

**버튼** — `조회` · `등록`(과제 PM 만) · `엑셀`

**탭** — 없음.

> ⚠ **이 섹션은 예시다 — 지우고 시작한다.** 화면 그림이 필요하면
> `work/assets/<작업id>/` 에 두고 여기서 링크한다.

### 예시 — 어휘

```
## 화면설계서

- `화면설계서:EXA010` — (예시) 과제접수목록
  example: 서식 예시 — 지우고 시작한다
  aliases: 과제접수 목록화면, 접수목록
```
