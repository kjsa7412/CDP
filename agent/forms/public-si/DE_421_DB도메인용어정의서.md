<!-- form:head -->
표준 용어의 지금 상태. **섹션 하나가 용어 하나**다.

<!-- form:guide -->
**무엇** — 논리명 하나에 물리명 하나를 못 박는다. 같은 뜻을 두 이름으로 쓰는
것을 막는 자리다.
**언제** — 설계 초반에 만든다. **테이블을 만들기 전에** 있어야 한다.
**누가** — DB 설계 담당.

**여기 적지 않는 것**

| | 어디로 |
|---|---|
| 어느 테이블의 어느 컬럼인가 | `테이블정의서` |
| 코드값 목록 | `코드정의서` |
| 업무 용어의 뜻(비 DB) | 필요하면 `_vocab.md` 의 `aliases` |

> **분류는 `<!-- 분류 -->` 주석이고 `##` 이 좌표다.** 분류를 제목으로 쓰면 좌표로 잡힌다.
> **하위 제목을 쓰지 않는다** — 볼드로 적는다.
>
> **동명이의를 조심한다.** 같은 논리명이 두 번 나오면 파서는 **앞의 것만**
> 찾고 뒤는 도달할 수 없다. 원본에서 실제로 5건 있었다 — 같은 논리명에
> 물리명이 둘이었다. 하나를 정본으로 정하고 나머지는 `_vocab.md` 의
> `aliases` 로 건다.

### 작성지침

| 항목 | 작성방법 | 필수 |
|---|---|:--:|
| 분류 | `<!-- <분류> -->` 주석. 접미어 계열이나 업무로 묶는다 | 필수 |
| 섹션 제목 | `## <논리명>`. **한글 붙여쓰기** — 공백이 있으면 좌표가 안 된다 | 필수 |
| 물리명 | 대문자 스네이크. 어절 약어를 이어 붙인다 | 필수 |
| 타입 | 접미어가 정하는 타입을 따른다 | 필수 |
| 어절 | 논리명을 쪼갠 것. 새 약어를 만들 때 근거가 된다 | 선택 |
| 접미어 | `AMT` · `CD` · `YN` · `DTS` 등. 괄호에 그 타입 규칙을 | 필수 |
| 코드구분 | 코드 컬럼이면 `코드정의서:<구분>` 을 가리킨다 | 선택 |
| 하위 제목 | **쓰지 않는다.** 볼드로 적는다 | — |

> **규모를 재 두었다.** 용어 4,671개 + 테이블 76개에서 레포 검사(`check`)가
> **0.55초**다. 섹션 48개짜리 레포와 같다 — 시간은 Node 기동에 묻힌다.

### 예시 — 예시계약금액

| | |
|---|---|
| 물리명 | `EX_CNTRCT_AMT` |
| 타입 | `BIGINT` |
| 어절 | 예시 + 계약 + 금액 |
| 접미어 | `AMT` (금액 → BIGINT) |

### 예시 — 예시참여율

| | |
|---|---|
| 물리명 | `EX_PTCP_RTE` |
| 타입 | `NUMERIC(5,2)` |
| 어절 | 예시 + 참여 + 율 |
| 접미어 | `RTE` (율 → NUMERIC) |

### 예시 — 예시진행상태코드

| | |
|---|---|
| 물리명 | `EX_PRGRS_STAT_CD` |
| 타입 | `VARCHAR(10)` |
| 접미어 | `CD` (코드 → VARCHAR) |
| 코드구분 | `코드정의서:EX010` |

> ⚠ **세 용어 다 예시다 — 지우고 시작한다.**

### 예시 — 어휘

```
## 도메인용어

- `도메인용어:예시계약금액` — (예시) 금액 도메인
  example: 서식 예시 — 지우고 시작한다
- `도메인용어:예시참여율` — (예시) 비율 도메인
  example: 서식 예시 — 지우고 시작한다
- `도메인용어:예시진행상태코드` — (예시) 코드 도메인
  example: 서식 예시 — 지우고 시작한다
```
