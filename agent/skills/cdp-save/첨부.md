# 첨부 — 그림 · pdf · HTML 시각 자료

화면 캡처 · 구성도 · 사양 pdf · 큰 추출물을 기록에 붙일 때다. **「첨부는 못 한다」 로 멈추지 않는다** — 사람에게 레포를 받아 올리라고 하지도 않는다. 파일은 **작업 기록에 딸린다** — 자리는 `work/assets/<작업 기록 id>/<이름>` 이고 기록과 한 커밋에 들어간다.

## 올리고 `ref` 를 싣는다

바이트는 도구 인자로 보내지 않는다 — 모델이 파일을 옮겨 적으면 수십만 토큰이고 한 글자만 틀려도 깨진 그림이 커밋된다. 셸에서 올린다. 서버 주소와 레포는 작업 레포 `.claude/cdp.json` 의 `server` · `repo`, 토큰은 MCP 가 쓰는 그 `CDP_TOKEN` 이다.

```bash
curl -sS -H "Authorization: Bearer $CDP_TOKEN" --data-binary @"docs/캡처/첨부영역.png" "<server>/api/<repo>/assets"
# → { "ref": "sha256:9f2c…", "size": 48213, "type": "image/png", "expiresInHours": 24 }
```

PowerShell 이면 `curl.exe`(그냥 `curl` 은 다른 명령이다)와 `$env:CDP_TOKEN` 으로 같은 것을 한다.

받은 `ref` 를 `save` 의 `assets: [{ ref, name: "첨부영역.png" }]` 에 싣고, 본문에 링크를 적는다. 올리기만으로는 레포가 바뀌지 않는다 — 서버가 24시간 들고 있다가 **`save` 가 기록과 한 커밋에 넣는다**(검사에서 걸리면 같이 되돌린다). 응답의 `assets: [{ path, size }]` 가 들어간 자리다.

| 올리기 응답 | |
|---|---|
| `401` · 셸에 `CDP_TOKEN` 이 없다 | 사람에게 토큰을 청하지 말고 그대로 알린다 — 설치 한 줄이 넣는 값이다 |
| `403` | 쓰기 권한이 없다 — 관리자에게 |
| `413` | 10 MB 를 넘는다 — 줄이거나 나눈다 |
| `415` | 받는 종류가 아니다 — 내용으로 가린다(확장자가 아니라). HTML 은 `<!doctype html` 또는 `<html` 로 시작하는 UTF-8 이어야 한다 |

받는 종류 — png · jpg · gif · webp · pdf · **html**. 하나에 10 MB · save 한 번에 20개 · 합 30 MB. svg 는 받지 않는다(png 로 바꾸거나 HTML 안에 인라인으로). 글(DDL · 덤프 · 로그)은 그대로는 안 받는다 — 한 장짜리 HTML 의 `<pre>` 로 싸서 올리고, 바뀐 값의 요지는 본문 표로 적는다.

## 링크

| 본문이 있는 곳 | 링크 |
|---|---|
| 작업 기록(`work/<id>.md`) — writer 가 쓰는 곳 | `![첨부 영역](assets/<id>/첨부영역.png)` |
| 관리 문서 섹션 — 큐레이터가 쓰는 곳 | 그 문서에서 본 상대경로 — `docs/X.md` 면 `![…](../work/assets/<id>/…)` · `docs/1.관리/X.md` 면 `../../work/assets/…` |

이름에 공백이 있으면 꺾쇠로 싼다 — `![구성도](<assets/<id>/시스템 개요.png>)`.

`save` 가 `warnings` 에 **「본문이 가리키는 그림 … 이 레포에 없다」** 를 내면 링크가 틀린 것이다(화면에 「그림을 찾을 수 없음」) — 위 표와 대 보고 정정 기록으로 고친다. **「올린 첨부 … 를 어느 본문도 가리키지 않는다」** 면 링크를 빠뜨린 것이다.

## HTML 시각 자료

구성도 · 시퀀스 · 넓은 표를 한 장짜리 HTML 로 만들었으면(클로드 코드가 흔히 내놓는 모양) **그대로 첨부한다** — md 로 옮기며 도면을 쪼개지 않는다. 화면은 그 문서 머리의 「본문 | 자료」 탭에서 격리된 틀로 연다. 다만 **검색 · 주입 · 큐레이션은 md 만 본다.**

| | 어디에 |
|---|---|
| 도면 · 색 구분 · 시퀀스 그림 · 넓은 표 | HTML(첨부) |
| **요지** — 무엇을 정했나 · 책임 구간 · 수치(규격) · **확인 목록** | 작업 기록 본문(md) |

- 그림(`![…]`)이 아니라 **링크**로 건다 — `[연계 구성도](assets/<id>/연계_구성도.html)`.
- 판이 바뀐 자료는 덮어쓰지 않는다 — 새 기록 · 새 경로로 올린다. 옛 기록이 가리키던 것이 몰래 바뀌면 안 된다.
- 외부 자원은 글꼴(Google Fonts)과 cdnjs · jsdelivr · unpkg 만 열린다. 그 밖(`<img src="https://…">` · 다른 CDN)은 화면이 막는다 — 인라인으로 넣는다. 폐쇄망이면 CDN 도 비므로 스크립트도 인라인이 낫다.
- 테마는 `:root[data-theme="dark"]` · `:root:not([data-theme="light"])` 로 받으면 화면 테마를 따른다.
- `save` 경고 「HTML 시각 자료 … 작업 기록 본문이 짧다」 → 요지를 md 로 더 적는다 · 「외부 자원 … 화면이 막는다」 → 인라인으로 · 「CDN … 폐쇄망에서는 빌 수 있다」 → 알고 넘어가거나 인라인으로.
