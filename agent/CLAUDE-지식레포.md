## 여기서 에이전트를 열지 않는다

이 레포는 서버가 쓴다 — 쓰는 길은 서버 `save` 하나다(한 번의 save 가 한 커밋). 이 폴더(clone)에서 파일을 고쳐
커밋 · push 하면 검사 · 큐레이션 판정을 거치지 않은 글이 들어가고 서버의 미러가 어긋난다. 여기서는 읽기만 한다.

에이전트 세션은 —

- **작업 레포**에서 — 설치 한 줄이 넣는 CDP 블록 · 스킬 `cdp-work` · `cdp-save` · `cdp-push`. 기록만 남긴다
- **큐레이터 폴더**에서 — 큐레이터 블록 · 스킬 `cdp-curate` · `cdp-registry`. 기록을 관리 문서에 반영한다

## 좌표 타입은 이 레포가 정한다

`_vocab.md` 의 `## <타입>` 이 그 목록의 전부다. 스킬 · 설명서 예시의 타입(`table:` · `screen:`)은 설명용이다 —
레포마다 다르다(`테이블정의서:ex_plan_mst` 처럼 한글 타입도 있다). 모르면 지어내지 말고 `match` 로 확정한다.

## 섹션의 모양

```
## <값> — <설명>
<!-- applied: … -->                         서버가 쓴다 — 반영한 기록 중 가장 늦은 것
(정본 서술 · 현재형)                          큐레이터
<!-- cdp:baseline src=… asof=… -->            기준선 — 코드 · DB 에서 기계로 뽑은 블록. 생성기만 쓴다
<!-- /cdp:baseline -->
**경과**                                     반영한 기록마다 한 줄
```

섹션은 큐레이터가 반영한 데까지만 지금이다 — 그 뒤 기록(미반영)은 `section` 도구와 화면이 섹션과 함께 낸다.
작업 기록에 상태(`status`) 필드는 없다 — 작업 기록은 작업의 완료에서 나온다.
