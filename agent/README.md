# agent — 클로드코드 세팅 정본

**여기가 원본이다.** 지식 레포나 sample-repo 안의 같은 파일은 전부 사본이고,
`ops\seed.cmd` · `ops\release.cmd` 가 여기서 복사해 만든다. 사본을 고치면
다음 빌드에 덮인다.

```
skills/                 절차 4종 — cdp-work · cdp-load · cdp-save · cdp-managed
CLAUDE-지식레포.md       지식 레포의 CLAUDE.md 로 들어간다
CLAUDE-프로젝트레포.md    코드가 있는 프로젝트 레포의 CLAUDE.md 로 들어간다
TEMPLATE-work.md        작업 기록 서식
```

## CLAUDE.md 가 왜 둘인가

레포가 둘이기 때문이다. **지식 레포**는 자기 자신이 무엇인지 말해야 하고,
**프로젝트 레포**는 옆에 지식 레포가 있다는 것을 말해야 한다. 내용이 겹치지
않는다.

전에는 이 구분이 없어 `agent/CLAUDE.md` 하나뿐이었고, 그 하나가 프로젝트
레포판이었다. 그래서 `seed` 와 `release` 가 **지식 레포 자리에 프로젝트판을
넣고 있었다.** 같은 시기에 지식 레포판은 파이썬 두 파일에 문자열로 각각 박혀
있다가 이미 갈라져 있었다 — 한쪽은 '산출물', 다른 쪽은 '산출물 16종'.

이름에 용도를 적어 두는 이유가 그것이다.
