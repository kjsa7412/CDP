붙은 한 벌이다.

## 붓는다

```
xcopy /E /I <배포본>\knowledge-repo-dpms C:\cdp
cd /d C:\cdp
git init && git config core.hooksPath .githooks
```

부으면 `_vocab.md` 가 생기고 **그 순간 그 폴더가 지식 레포**가 된다.
바로 `ctx check` 가 돈다 — 작업 기록이 0건이면 `이상 없음` 이다.

## 첫날 무엇을 하나

```
1  안 쓰는 문서를 지운다            46개를 다 쓰는 프로젝트는 드물다
2  _managed.md 에서 그 패턴을 지운다  없는 문서를 가리키면 커밋이 막힌다
3  문서마다 예시 섹션을 지운다       `(예시)` 가 붙어 있다
4  _vocab.md 에 좌표를 등록한다      여기 없는 좌표를 쓰면 커밋이 막힌다
5  ctx check                       이상 없음이 나오면 시작할 수 있다
```

**2를 빠뜨리면 조용하지 않다.** `등록부가 가리키는 섹션이 없음` 으로 막힌다 —
그게 이 시스템이 값을 하는 자리다.
