# 기능정의서

기능의 지금 상태. 섹션 하나가 기능 하나다.

| | |
|---|---|
| 관리번호 | `GDI_AN_221` |
| 제출시기 | 분석완료 |
| 필수 제출 | 아니오 |
| 등록부 | `func:*` → `## {값}` |
| 좌표 값 | 기능 ID |

**무엇** — 업무를 기능 단위로 쪼개고, 각 기능이 **업무 흐름의 어느 단계**에
놓이는지와 **어느 프로그램이 그것을 구현하는지**를 잇는다.
**언제** — 분석에서 만들고, 기능이 늘거나 프로그램 배정이 바뀌면 고친다.
**누가** — 업무 담당 PL.

**여기 적지 않는 것**

| | 어디로 |
|---|---|
| 흐름의 순서와 분기 | `프로세스정의서` |
| 화면 레이아웃 · 동작 | `화면설계서` · `프로그램사양서` |
| 왜 필요한가 | `요구사항정의서` |

> **원본은 단계를 가로 8칸으로 펼쳐 두었다.** 기능 하나가 그중 한 칸에 놓여
> 흐름상 위치를 나타냈는데, 7칸이 늘 비었다. 여기서는 **값 하나로 접는다** —
> 표의 가로 위치는 엑셀에서 눈으로 보려던 장치이지 데이터가 아니다.

## EX-FNC-RP-01 — (예시) 연구과제 접수
<!-- applied: null -->

| | |
|---|---|
| 서비스 | 연구과제 |
| 분류 | 연구과제선정 › 과제접수 |
| 단계 | 2 (선택) |
| 담당 | 과제 PM |
| 프로그램 | `prog:EXA010` 과제접수목록 · `prog:EXA011` 과제접수등록 |

**내용** — 연구과제 수행의 첫 단계. 제안서를 붙여 접수하고, 접수되면
사전검토로 넘어간다. 임시저장 상태에서는 검토 대상에 뜨지 않는다.

> ⚠ **이 섹션은 예시다 — 지우고 시작한다.**
