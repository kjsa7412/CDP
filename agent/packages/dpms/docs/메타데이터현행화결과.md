# 메타데이터현행화결과

메타데이터를 맞춘 결과. 행 하나가 맞춘 대상 하나다.

| | |
|---|---|
| 관리번호 | `GDI_DE_441` |
| 제출시기 | 설계완료 |
| 필수 제출 | 아니오 |
| 등록부 | **비대상** — 집계다 |

**무엇** — 표준 용어 · 도메인 · 코드가 실제 DB 와 **어긋난 것을 찾아 맞춘
기록**. 무엇을 어떻게 고쳤는지를 남긴다.
**언제** — 설계 후반. 테이블정의서와 DB도메인용어정의서가 어느 정도 찬 뒤.
**누가** — DB 설계 담당.

**여기 적지 않는 것**

| | 어디로 |
|---|---|
| 표준 용어 자체 | `DB도메인용어정의서` |
| 테이블 · 컬럼 구성 | `테이블정의서` |

> **이 문서는 "했다" 의 기록이다.** 표준 자체는 다른 문서가 갖는다. 여기에
> 표준을 다시 적으면 정본이 둘이 된다.

| 대상 | 항목 | 현행화 전 | 현행화 후 | 일자 | 담당 | 비고 |
|---|---|---|---|---|---|---|
