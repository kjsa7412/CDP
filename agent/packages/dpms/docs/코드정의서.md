# 코드정의서

공통코드의 지금 상태. **섹션 하나가 코드구분 하나**다 — 코드 하나하나가
아니다.

| | |
|---|---|
| 관리번호 | `GDI_AN_251 · GDI_DE_423` |
| 제출시기 | 분석완료 · 설계완료 |
| 필수 제출 | 아니오 |
| 등록부 | `code:*` → `## {값}` |
| 좌표 값 | 업무구분 + 구분코드 |

**무엇** — 코드구분마다 그 안에 어떤 값이 있는지를 표로 둔다.
**언제** — 설계에서 만들고, 값이 늘거나 뜻이 바뀌면 고친다.
**누가** — 업무 담당 PL.

**여기 적지 않는 것**

| | 어디로 |
|---|---|
| 어느 테이블의 어느 컬럼이 이 코드를 쓰나 | `테이블정의서` 가 `code:<구분>` 으로 가리킨다 |
| 코드 컬럼의 물리명 규칙 | `DB도메인용어정의서` |

> **코드 하나를 섹션으로 잡지 않는다.** 사람은 *"연구분류에 뭐가 있나"* 를
> 묻지 *"정책과제 코드가 어떻게 생겼나"* 를 묻지 않는다. 구분 단위면
> 181개 안팎이고, 코드 단위면 수천 개가 된다.
