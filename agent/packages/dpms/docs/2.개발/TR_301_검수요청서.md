# TR_301 검수요청서

날짜축. 검수를 **요청한 사건**과 그 결과가 회차마다 쌓인다.

| | |
|---|---|
| 관리번호 | `TR_301` |
| 제출시기 | 이행완료 |
| 필수 제출 | 아니오 |
| 등록부 | **비대상** — 날짜축이다 |

**무엇** — 계약한 것을 다 했으니 확인해 달라고 내는 문서. **무엇을 근거로
그렇게 말하는지**를 함께 건다.
**언제** — 이행 완료 후. 발주처 검수 일정에 맞춘다.
**누가** — PM.

**여기 적지 않는 것**

| | 어디로 |
|---|---|
| 요구사항을 다 했는지의 근거 | `요구사항정의서` — 좌표마다 실린 작업이 근거다 (`ctx where req:…`) |
| 시험 결과 | `통합테스트결과서` |
| 수행 결과 전체 | `완료보고서` |

> **발주처 양식이 우선이다.** 원본으로 참고한 것은 다른 프로젝트의
> `검수확인서` 였고 이 서식과 이름부터 다르다 — **요청서와 확인서는 다른
> 문서**다. 발주처가 주는 양식이 있으면 그것을 쓰고, 이 서식은 **무엇을
> 빠뜨리지 말아야 하는지**의 점검표로 쓴다.
>
> 그리고 **`.hwp` 로 오는 경우가 많다.** 그때 정본은 그 파일이고, 여기에는
> 언제 무엇을 근거로 요청했는지만 남긴다.
