# TE_202 성능테스트시나리오

성능테스트의 지금 상태. 섹션 하나가 **프로그램 하나**다.

| | |
|---|---|
| 관리번호 | `TE_202` |
| 제출시기 | 테스트완료 |
| 필수 제출 | 아니오 |
| 등록부 | `시험시나리오:PT-*` → `## {값}` |
| 좌표 값 | `PT-` + 프로그램ID |

**무엇** — 부하를 걸었을 때 **버티는가**를 확인하는 절차다. 기능이 맞는지는 보지
않는다.
**언제** — 테스트 단계에서 만든다. 목표치는 요구사항정의서의 성능 요구에서 온다.
**누가** — 성능 담당

**여기 적지 않는 것**

| | 어디로 |
|---|---|
| 밟은 결과 · PASS/FAIL · 수정요청 | `성능테스트결과서` — **회차마다 쌓이는 사건**이다 |
| 언제 누가 모여서 하나 | `성능테스트계획서` |
| 화면 생김새 | `화면설계서` |

> **시나리오는 상태이고 결과는 사건이다.** 절차와 점검사항은 대상에
> 붙어 갱신되지만, 밟은 결과는 회차마다 따로 남는다. 원본은 한 시트에
> 섞어 두었는데 그러면 지난 회차가 덮인다.

## PT-EXA010 — (예시) 과제접수목록
<!-- applied: null -->

| | |
|---|---|
| 모듈 | 연구과제 › 과제접수 |
| 프로그램 | `프로그램사양서:EXA010` |
| 담당 | 개발 담당 |

**절차**

| # | 구분 | 무엇을 |
|--:|---|---|
| 1 | 준비 | 대상 데이터 10만 건을 적재한다 |
| 2 | 부하 | 동시 사용자 50명으로 5분간 조회를 반복한다 |
| 3 | 측정 | 평균 · 95퍼센타일 응답시간과 오류율을 기록한다 |

**중점 점검사항**

- 평균 응답 **2초 이내** (`요구사항:EX-PER-01`)
- 오류율 **1% 미만**
- DB CPU **80% 미만**

> ⚠ **이 섹션은 예시다 — 지우고 시작한다.**
