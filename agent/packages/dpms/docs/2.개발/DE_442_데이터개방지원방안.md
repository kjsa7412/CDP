# DE_442 데이터개방지원방안

서술형. **문서 전체가 내용**이라 쪼갤 대상이 없다 — 등록부에 올리지 않는다.

| | |
|---|---|
| 관리번호 | `DE_442` |
| 제출시기 | 설계완료 |
| 필수 제출 | 아니오 |
| 등록부 | **비대상** — 문서 전체가 내용이다 |

**무엇** — 만든 데이터를 **밖에 어떻게 열 것인가**. 공공데이터 개방이 요구에 있으면
그 계획과 결과.
**언제** — 설계. 개방 요구가 있을 때만.
**누가** — 데이터 담당.

**여기 적지 않는 것**

| | 어디로 |
|---|---|
| 메타데이터를 맞춘 기록 | `메타데이터현행화결과` |
| 연계 건별 상세 | `인터페이스정의서` |
| 테이블 구성 | `테이블정의서` |

> **요구가 없으면 이 문서를 지운다.** 지울 때 `_managed.md` 는 건드릴 것이
> 없다 — 등록부 비대상이다. 다만 `형상관리대장` 에서 그 행도 함께 뺀다.
