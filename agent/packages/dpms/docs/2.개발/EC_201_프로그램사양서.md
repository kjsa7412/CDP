# EC_201 프로그램사양서

프로그램 구현의 지금 상태. 화면설계서와 **같은 좌표 값**을 쓴다 — 설계면과
구현면이다.

| | |
|---|---|
| 관리번호 | `EC_201` |
| 제출시기 | 구현완료 |
| 필수 제출 | 아니오 |
| 등록부 | `prog:*` → `## {값}` |
| 좌표 값 | 프로그램ID · 하위프로그램ID |

**무엇** — 그 프로그램이 **어떤 동작에서 어떤 테이블을 읽고 쓰는가**를 적는다.
화면설계서가 "무엇이 보이나" 라면 여기는 "그래서 무엇이 일어나나" 다.
**언제** — 구현하면서 만들고, 동작이나 테이블이 바뀌면 고친다.
**누가** — 그 프로그램을 개발한 사람.

**여기 적지 않는 것**

| | 어디로 |
|---|---|
| 화면 레이아웃 · 버튼 | `화면설계서` — 같은 좌표 값의 설계면 |
| 테이블의 컬럼 구성 | `테이블정의서` — 여기서는 `table:<이름>` 을 가리킨다 |
| 외부 연계 | `인터페이스정의서` |

**처리 규칙**

- 확정 뒤에는 수정할 수 없다 — 버튼을 감추지 말고 **비활성으로** 둔다
- 등록자와 과제 PM 이 다르면 등록 버튼이 뜨지 않는다

> ⚠ **이 섹션은 예시다 — 지우고 시작한다.**

## 작성지침

| 항목 | 작성방법 | 필수 |
|---|---|:--:|
| 섹션 제목 | `<프로그램ID> — <프로그램명>`. 화면설계서와 **같은 값** | 필수 |
| 개발유형 | 화면 / 배치 / API / 출력물 | 필수 |
| 동작 · 테이블 | 동작마다 한 행. 테이블은 `table:<이름>` 으로 **가리킨다** | 필수 |
| 처리 규칙 | 표로 안 되는 조건 · 권한 · 금지 | 필수 |
| 변경 | `**변경** · 날짜 [작업기록](../../work/…) 무엇이` | 작업 후 필수 |

> **테이블 컬럼을 여기 베끼지 않는다.** 베끼면 테이블정의서와 갈라지고,
> 갈라진 순간 어느 쪽이 맞는지 알 수 없다. 좌표로 가리키면 뷰어가 이어 준다.
