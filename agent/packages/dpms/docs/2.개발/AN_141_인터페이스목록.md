# AN_141 인터페이스목록

연계의 집계. 행 하나가 인터페이스 하나다. **건별 상세는
`인터페이스정의서` 가 갖는다.**

| | |
|---|---|
| 관리번호 | `AN_141` |
| 제출시기 | 분석완료 |
| 필수 제출 | 아니오 |
| 등록부 | **비대상** — 집계다 |

**무엇** — 주고받는 것이 몇 건이고 각각 어느 시스템과 붙는지. 분석 단계에서
**연계 범위를 확정**하는 자리다.
**언제** — 분석에서 만든다. 설계에서 정의서로 넘어간다.
**누가** — 연계 담당.

**여기 적지 않는 것**

| | 어디로 |
|---|---|
| 컬럼 매핑 · 주기 · 실패 처리 | `인터페이스정의서` |
| 연계 경로의 큰 그림 | `시스템아키텍처정의서` 의 `시스템아키텍처:link` |

> **정의서가 생기면 이 목록은 집계로 남는다.** 둘 다 손으로 유지하면
> 갈라진다 — 새 인터페이스는 **정의서에 먼저** 쓰고 여기 한 줄을 더한다.

| 인터페이스ID | 명 | 상대 시스템 | 방향 | 처리형태 | 사용 | 비고 |
|---|---|---|---|---|:--:|---|
| (예시) `EX-INT-1001` | 거래처정보 수신 | 외부시스템 | 수신 | Batch 24h | Y | |
| (예시) `EX-INT-1002` | 결의서 송신 | 회계시스템 | 송신 | Batch 1h | Y | |
| (예시) `EX-INT-1003` | 알림 발송 | 메신저 | 송신 | 실시간 | N | 2차에서 |

> ⚠ **예시 행이다 — 지우고 시작한다.**
