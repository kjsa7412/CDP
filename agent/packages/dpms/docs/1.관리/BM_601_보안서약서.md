**무엇** — 투입 인력이 **무엇을 지키겠다고 약속하는지**의 양식과, 누가 언제 냈는지의
현황.
**언제** — 착수 시 투입 인력 전원. **계약상 필수 제출물**이다.
인력이 추가 투입되면 그때 받는다.
**누가** — PM 이 취합한다.

**여기 적지 않는 것**

| | 어디로 |
|---|---|
| 서명한 원본 | **여기 두지 않는다.** 종이 또는 발주처 시스템 |
| 개인정보(주민번호 · 연락처) | **여기 두지 않는다** — 이 레포는 git 이력에 남는다 |

> **이 문서에 사람 이름과 개인정보를 넣지 마라.** 지식 레포는 git 이고
> clone 되어 팀 전체에 퍼진다. 한 번 들어간 것은 이력에서 지우기 어렵다.
> 현황은 **역할과 날짜**로 충분하고, 서명 원본은 발주처 절차를 따른다.

## 제목 뼈대

아래 절을 채운다. **발주처 양식이 있으면 그것이 우선**이고, 이 뼈대는
무엇을 빠뜨리지 말아야 하는지의 점검표로 쓴다.

| # | 절 | 무엇을 적나 |
|--:|---|---|
| 1 | 서약 목적 | 왜 받는가 |
| 2 | 대상 정보 | 무엇을 비밀로 보는가 — 소스 · 데이터 · 설계 · 계정 |
| 3 | 준수 사항 | 반출 금지 · 계정 공유 금지 · 반납 · 퇴사 후 의무 |
| 4 | 위반 시 | 책임 범위 |
| 5 | 서약 양식 | 서명란을 포함한 문면. **채우지 않은 빈 양식** |
| 6 | 제출 현황 | 이름 대신 **역할과 제출일**만. 예: `PL(설계) · 2026-01-05` |

> 제목은 자유롭게 쓴다 — **등록부 비대상이라 좌표와 충돌하지 않는다.**
