# BM_411 회의록

날짜축. 회의는 대상이 아니라 **사건**이라 좌표-섹션이 1:1로 대응하지 않는다.

| | |
|---|---|
| 관리번호 | `BM_411` |
| 제출시기 | 수시 |
| 필수 제출 | 아니오 |
| 등록부 | **비대상** — 날짜축이다 |

**무엇** — 그 자리에서 **무엇이 오갔고 무엇이 정해졌는지**. 특히 정해진 것과
안 정해진 것을 갈라 놓는다.
**언제** — 회의 당일. 다음 날로 넘기면 누가 뭐라 했는지 흐려진다.
**누가** — 주관자 또는 지명된 기록자.

**여기 적지 않는 것**

| | 어디로 |
|---|---|
| 거기서 나온 **요구사항** | `요구사항정의서` — 여기는 출처로 가리켜진다 |
| 거기서 드러난 **위험 · 미결** | `위험및이슈관리대장` |
| 거기서 내린 **설계 결정** | 작업 기록(`work/`) — 판단이 끝났으면 지식이다 |

> **회의록은 옮겨 적는 곳이 아니라 가리켜지는 곳이다.** 요구사항정의서의
> `출처` 가 이 문서의 한 날짜를 가리킨다. 원본에서도 그렇게 돼 있었다 —
> 현업 요구 130건이 회의록 파일 7개를 출처로 달고 있었다.
>
> **`cdp-import` 로 들이면 작업 기록이 된다.** 밖에서 온 회의록을 그대로
> 편입할 때 쓴다 — 그때는 좌표가 붙고 원문이 보존된다.
