# 개발가이드

서술형. **문서 전체가 내용**이라 쪼갤 대상이 없다 — 등록부에 올리지 않는다.

| | |
|---|---|
| 관리번호 | `GDI_DE_311` |
| 제출시기 | 구현완료 |
| 필수 제출 | 아니오 |
| 등록부 | **비대상** — 문서 전체가 내용이다 |

**무엇** — 코드를 쓸 때 지킬 규칙. 원본은 PGM · WEB · SQL · REPORT 네 벌이었다 —
**한 문서에 절로 나눈다.**
**언제** — 개발 준비 단계. 첫 프로그램을 만들기 전에.
**누가** — 개발 PL.

**여기 적지 않는 것**

| | 어디로 |
|---|---|
| DB 명명 · 타입 | `DB개발가이드` |
| 프로그램별 구현 내용 | `프로그램사양서` |
| 화면 구성 규칙 중 **업무 규칙** | `업무규칙정의서` |

> **원본은 네 파일이었다.** 파일이 나뉘면 "이건 어느 가이드에 있지" 를
> 매번 묻게 된다. 한 문서에 절로 나누면 검색 한 번이다.
