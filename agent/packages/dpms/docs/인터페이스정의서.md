# 인터페이스정의서

연계의 지금 상태. 섹션 하나가 인터페이스 하나다. 요약과 컬럼 매핑을 한 섹션에 둔다.

| | |
|---|---|
| 관리번호 | `GDI_DE_451` |
| 제출시기 | 설계완료 |
| 필수 제출 | 아니오 |
| 등록부 | `api:*` → `## {값}` · `batch:*` → `## {값}` |
| 좌표 값 | 인터페이스 ID · 배치 Object |

> 섹션마다 `applied` 주석이 있다. 그 작업 기록 이후에 같은 좌표를 건드린
> 작업이 있으면 파생이 남은 것이고, **그것은 오류다** — `ctx check` 가
> 커밋을 막는다.
