## 작성지침

| 항목 | 작성방법 | 필수 |
|---|---|:--:|
| WBS | `1.1.1.1` 점 표기. **계층이 곧 번호다** | 필수 |
| 작업 | 동사로 끝낸다 — "작성" · "검토" · "수행" | 필수 |
| 계획 시작 · 완료 | `YYYY-MM-DD`. 착수 시 한 번 정하고 함부로 안 바꾼다 | 필수 |
| 실제 시작 · 완료 | 진행하며 채운다. **완료가 빈 채로 계획 완료가 지나면 지연이다** | 진행 시 필수 |
| 담당 | 역할. 사람 이름을 쓰면 인사이동 때 전부 고쳐야 한다 | 필수 |
| 산출물 | 그 작업이 내는 문서명. **이 문서 목록과 같은 이름을 쓴다** | 산출 시 필수 |

> **계획을 고쳤으면 왜 고쳤는지가 어딘가 있어야 한다.** 이 표에는 자리가
> 없다 — `위험및이슈관리대장` 이나 주간보고의 이슈 절에 남긴다.
