# 테이블정의서

테이블의 지금 상태. 섹션 하나가 테이블 하나다.

| | |
|---|---|
| 관리번호 | `GDI_DE_422` |
| 제출시기 | 설계완료 |
| 필수 제출 | 아니오 |
| 등록부 | `table:*` → `## {값}` |
| 좌표 값 | 테이블 물리명(소문자) |

**무엇** — 테이블마다 컬럼 구성과 제약(타입 · NULL · 키 · 기본값)을 적는다.
**언제** — 설계에서 만들고, 그 뒤로는 **테이블을 바꿀 때마다** 그 섹션을 고친다.
**누가** — DB 설계 담당이 만들고, 개발 중 컬럼을 바꾼 사람이 고친다.

**여기 적지 않는 것** — 섞이면 정본이 둘이 된다.

| | 어디로 |
|---|---|
| 엔터티 사이의 관계 · 카디널리티 | `ERD모델링` |
| 이관 대상 여부 · 진행 상황 | `데이터이관정의서` |
| 코드값 목록 | `코드정의서` — 여기서는 `code:EX010` 처럼 **가리키기만** 한다 |
| 논리명의 표준 어휘 | `DB도메인용어정의서` |

> 섹션마다 `applied` 주석이 있다. 그 작업 기록 이후에 같은 좌표를 건드린
> 작업이 있으면 파생이 남은 것이고, **그것은 오류다** — `ctx check` 가
> 커밋을 막는다.

<!-- 연구과제 -->

## ex_plan_mst — (예시) 계획서마스터
<!-- applied: null -->

| | |
|---|---|
| DB USER | `dbo` |
| AS-IS | `EX_PLAN_M` — **이관이 끝나면 이 줄을 지운다** |

| 컬럼 | 타입 | NULL | 키 | 기본값 | 설명 |
|---|---|:--:|:--:|---|---|
| `PLAN_ID` | VARCHAR(20) | N | PK | | 계획서ID |
| `PRJ_ID` | VARCHAR(20) | N | FK | | 과제ID |
| `PLAN_STAT_CD` | VARCHAR(10) | Y | | `10` | 계획서상태코드 · `code:EX010` |
| `PLAN_NM` | VARCHAR(100) | Y | | | 계획서명 |
| `USE_YN` | VARCHAR(1) | N | | `Y` | 사용여부 |
| `FIRS_REG_USER_ID` | VARCHAR(20) | Y | | | 최초등록자ID |
| `FIRS_REG_DTS` | TIMESTAMP(0) | Y | | SYSDATE | 최초등록일시 |

**특이사항** — `PLAN_STAT_CD` 는 `40`(확정) 이후 수정되지 않는다.

**변경** · 2026-01-15 [`계획서-상태값추가`](../work/2026-0115-계획서-상태값추가.md) `PLAN_STAT_CD` 에 `50`(반려) 추가

> ⚠ **이 섹션은 예시다 — 지우고 시작한다.**
>
> 실제로는 `applied` 에 위 `변경` 이 가리키는 작업 기록 id 를 적는다. 여기서
> 비워 둔 것은 **그 기록이 실제로 없기 때문**이다 — 없는 id 를 적으면
> `ctx check` 가 `applied 가 없는 작업 기록을 가리킴` 으로 커밋을 막는다.

## 작성지침

| 항목 | 작성방법 | 필수 |
|---|---|:--:|
| 섹션 제목 | `<물리명 소문자> — <논리명>`. 값에 ` - `(공백-하이픈-공백)를 쓰지 않는다 | 필수 |
| `applied` | 이 섹션에 반영한 작업 기록 id. 아직 없으면 `null` | 필수 |
| DB USER | 스키마가 하나면 생략해도 된다 | 선택 |
| AS-IS | 이관 중에만. 끝나면 **그 줄을 지운다** | 선택 |
| 컬럼 표 | TO-BE 기준. 타입은 DBMS 표기 그대로(`VARCHAR(20)`) | 필수 |
| NULL | `N` = Not Null · `Y` = 허용 | 필수 |
| 키 | `PK` · `FK` · 빈칸 | 필수 |
| 설명 | 논리명. 코드 컬럼이면 `code:<구분>` 을 덧붙인다 | 필수 |
| 특이사항 | 표로 안 되는 제약 · 운영 주의 | 선택 |
| 변경 | `**변경** · 날짜 [작업기록](../work/…) 무엇이`. **제목이 아니라 볼드** | 작업 후 필수 |
