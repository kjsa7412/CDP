# PF_101 시스템아키텍처

시스템 구성의 지금 상태. **좌표 넷이 고정이다** — 어느 클라우드 네이티브 시스템에나 있는
관점이라 값으로 박아 두었다.

| | |
|---|---|
| 관리번호 | `PF_101` |
| 언제 | 첫 서비스를 올리기 전 · 서비스 지도 · 플랫폼 구성 · 진입점 · 보안 경계가 바뀔 때 |
| 등록부 | `시스템아키텍처:*` → `## {값}` |
| 좌표 값 | `context` · `platform` · `network` · `security` **넷 고정** |

**무엇** — 서비스들이 서로 · 바깥과 어떻게 이어지나(`context`), 서비스가 무엇 위에서 도나(`platform`),
요청이 어디로 들어와 어디로 나가나(`network`), 어디에 신뢰 경계가 있고 무엇이 지키나(`security`).
**언제** — 플랫폼을 세울 때 초안. 클러스터 · 메시 · 진입점 · 경계를 바꾸면 그 섹션을 고친다.
**누가** — 플랫폼 팀 · 아키텍트.

**여기 적지 않는 것**

| | 어디로 |
|---|---|
| 서비스 하나하나의 책임 · 의존 | `서비스명세` |
| 환경마다의 계정 · 리전 · 클러스터 이름 | `인프라구성` |
| 배포 흐름 · 게이트 | `배포파이프라인` |
| IAM · 비밀 · 공급망 규칙 | `보안기준` |
| 차트 · 매니페스트 · 테라폼 값 | 코드 레포(GitOps · IaC) |
| 왜 이 메시 · 이 인그레스인가 · 견준 안 | 작업 기록(`work/`) |

> **넷은 서식 예시가 아니다** — 섹션은 두고 안의 (예시) 행만 바꾼다. 늘리거나 줄이려면
> **`_vocab.md` 의 `## 시스템아키텍처` 절과 이 문서를 함께** 고친다.

## network — 네트워크 · 진입점
<!-- applied: null -->

(예시) 바깥에서 주문 API 까지 —

1. **DNS · CDN · WAF** — `api.example.shop` · 봇 · 공격 차단 · 정적 자원 캐시
2. **로드밸런서 → 게이트웨이** — TLS 종료 · 인증 토큰 검사 · 한도
3. **서비스 메시** — 서비스 사이 mTLS · 재시도 · 시간 초과 · 서킷 브레이커
4. **나가는 길** — NAT 고정 IP 둘(결제 대행사 허용 목록) · 그 밖의 바깥 호출은 막는다

> ⚠ **예시 행이다 — 지우고 시작한다.**

## security — 보안 경계
<!-- applied: null -->

| 경계 | 무엇이 지키나 |
|---|---|
| (예시) 인터넷 ↔ 엣지 | WAF · DDoS 방어 · 한도 |
| (예시) 엣지 ↔ 서비스 | 게이트웨이의 토큰 검사(OIDC) · 외부에 연 API 만 노출 |
| (예시) 서비스 ↔ 서비스 | mTLS · 워크로드 신원 · 네트워크 정책 기본 거부 |
| (예시) 파드 ↔ 클라우드 API | 워크로드 아이덴티티 · 서비스마다 최소 권한 역할 · 장기 키 없음 |
| (예시) 사람 ↔ 클러스터 | SSO · 단기 자격 · 운영은 읽기 전용 기본 · 감사 로그 |

> ⚠ **예시 행이다 — 지우고 시작한다.**

## 작성지침

| 항목 | 작성방법 | 필수 |
|---|---|:--:|
| 섹션 | **넷 고정.** 늘리거나 줄이려면 `_vocab.md` 의 `## 시스템아키텍처` 절도 함께 고친다 | 필수 |
| `applied` | 넷 다 `null` 로 시작한다 | 필수 |
| `context` | 도메인 · 서비스 · 등급 · 이어지는 곳 · 바깥 업체. 서비스는 `서비스명세:` 좌표로 | 필수 |
| `platform` | 구성 요소마다 한 행. **판을 반드시 적는다** — 장애 때 무엇을 의심할지 정한다 | 필수 |
| `network` | 들어오는 길 · 나가는 길을 **번호 목록**으로. 고정 IP · 허용 목록을 빠뜨리지 않는다 | 필수 |
| `security` | 경계마다 무엇이 지키나. 규칙 자체는 `보안기준` 에 | 필수 |
| 그림 | `work/assets/` 에 두고 링크. 흐름은 번호 목록 · 표로 적는다 | 선택 |
| 변경 | `**변경** · 날짜 [작업기록](../../work/…) 무엇이` | 작업 후 필수 |
