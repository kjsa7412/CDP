# EV_101 평가셋

평가셋의 지금 상태와 **출시 기준**. 섹션 하나가 평가셋 하나다. 데이터는 여기 없다.

| | |
|---|---|
| 관리번호 | `EV_101` |
| 언제 | 평가셋을 만들거나 늘릴 때 · 출시 기준을 바꿀 때 · 모델 · 프롬프트 · 지식소스를 바꿔 다시 잰 뒤 |
| 등록부 | `평가셋:*` → `## {값}` |
| 좌표 값 | 평가셋 키 — 데이터 파일 · 평가 도구의 이름과 맞춘다 |

**무엇** — 무엇을 재나 · 크기 · 출처 · 채점(정답 대조 · LLM 심판 · 사람) · **출시 기준** · 최근 결과.
평가셋이 출시를 막는 문(게이트)이다.
**언제** — 기능을 만들 때 같이 세운다. 모델 · 프롬프트 · 지식소스를 바꾼 작업은 평가를 다시
돌리고 이 섹션의 「최근 결과」 를 고친다 — 그래서 그 작업들이 평가셋 좌표를 같이 적는다.
**누가** — 평가 담당 · 기능 담당 AI 엔지니어. 출시 기준을 바꾸는 것은 제품 책임자와 같이.

**여기 적지 않는 것**

| | 어디로 |
|---|---|
| 사례 데이터 원문 | 데이터 저장소(`정본 위치`) — 파일로 둔다 |
| 회차마다의 실험 · 비교 | `실험기록` — 여기는 **기준과 지금 수치**만 |
| 운영 중 품질 지표 | `운영모니터링` |
| 기준을 왜 그 숫자로 정했나 | 작업 기록(`work/`) |

> **출시 기준을 낮추는 것도 작업 기록이다.** 기준을 못 넘었는데 내보내기로 했으면 그 판단과
> 근거를 작업 기록에 남기고 이 섹션의 기준을 고친다 — 기준이 조용히 바뀌지 않는다.

## ex-support-golden — (예시) 상담 답변 골든셋

| | |
|---|---|
| 정본 위치 | (예시) 데이터 레포 `evals/support/golden.jsonl` · 판 2026-09-15 |
| 재는 것 | `기능명세:EX-SUPPORT-ANSWER` 의 품질 기준 — 근거 충실 · 정답 일치 · 개인정보 · 인젝션 저항 |
| 대상 | `프롬프트:ex-support-answer` · `모델카드:ex-answer-llm` · `지식소스:ex-help-center` |
| 크기 | 320 사례 — 일반 문의 240 · 까다로운 문의 40 · 인젝션 · 레드팀 40 |
| 출처 | 지난 분기 실제 문의에서 뽑아 개인정보를 가린 것 · 정답은 상담 운영이 썼다 |
| 채점 | 근거 충실 = LLM 심판(심판 모델 · 심판 프롬프트 판 고정) · 정답 일치 = 사람 5점 척도 표본 60 · 개인정보 = 규칙 검사 |
| 심판 검증 | 사람 채점과 심판의 일치율 0.85 이상일 때만 심판 점수를 쓴다 |

**출시 기준** — 하나라도 못 넘으면 내보내지 않는다.

| 지표 | 문턱 | 막는 실패 |
|---|---|---|
| 근거 충실 | 0.90 이상 | 환각 |
| 정답 일치(사람) | 4.0 / 5 이상 | 엉뚱한 안내 |
| 개인정보 노출 | 0건 | 유출 |
| 인젝션 저항 | 40 / 40 | 지시 탈취 |
| 지난 판 대비 회귀 | 일반 문의 −2%p 안 | 조용한 퇴보 |

**최근 결과** — 출시에 쓴 마지막 회차만. 회차마다의 기록은 `실험기록` 이 쌓는다.

## 작성지침

| 항목 | 작성방법 | 필수 |
|---|---|:--:|
| 섹션 제목 | `<평가셋 키> — <이름>` | 필수 |
| `applied` | 이 섹션에 반영한 작업 기록 id. 없으면 `null` | 필수 |
| 정본 위치 · 판 | 데이터 파일의 자리와 판. **사례를 옮겨 적지 않는다** | 필수 |
| 재는 것 · 대상 | 어느 기능의 어느 기준을 · 무엇(프롬프트 · 모델 · 지식소스)을 재나 — 좌표로 | 필수 |
| 크기 · 출처 | 묶음별 사례 수 · 어디서 왔나 · 개인정보를 가렸나 | 필수 |
| 채점 | 정답 대조 · LLM 심판 · 사람. 심판을 쓰면 **사람 표본으로 심판을 검증**한다 | 필수 |
| 출시 기준 | 지표 · 문턱 · 막는 실패. **지난 판 대비 회귀**를 넣는다 | 필수 |
| 최근 결과 | 출시에 쓴 회차 — 날짜 · 대상 판 · 수치 · 판정. 수치는 평가 도구에서 옮겨 적는다 | 필수 |
| 변경 | `**변경** · 날짜 [작업기록](../../work/…) 무엇이` | 작업 후 필수 |
