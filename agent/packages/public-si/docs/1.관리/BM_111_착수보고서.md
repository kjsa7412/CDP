날짜축. **보고는 사건**이다 — 그날 그렇게 보고했다는 기록이 남는다.

| | |
|---|---|
| 관리번호 | `BM_111` |
| 제출시기 | 착수 시 |
| 필수 제출 | **예** |
| 등록부 | **비대상** — 날짜축이다 |

**무엇** — 사업을 **어떻게 할 것인지**를 발주처와 맞추는 자리. 범위 · 일정 · 조직 · 방법론을 한 번에 보인다.
**언제** — 착수 직후. **계약상 필수 제출물**이다.
**누가** — PM 이 쓰고 PL 이 단계별로 채운다.

**여기 적지 않는 것**

| | 어디로 |
|---|---|
| 숫자의 근거 | `WBS` · `사업수행계획서` — 여기는 **요약**이다 |
| 설계 판단 | 작업 기록(`work/`) |
| 열린 이슈의 전체 이력 | `위험및이슈관리대장` |

> **요약을 여기서 다시 세지 않는다.** 근거 문서에서 옮겨 적고, 다르면
> 근거 쪽을 고친다. 보고서의 숫자가 원천이 되면 그 순간 두 벌이 된다.
