# blank — 빈 지식 레포

**문서 0 · 등록부 0 · 좌표 타입 0.** 도구(검사 · 훅 · 스킬 · 매뉴얼)만 들어오고 서식은 없다.
무엇을 정본 문서로 둘지 팀이 정하고, 첫 관리 문서를 직접 세운다.

## 이럴 때 고른다

| | |
|---|---|
| 맞는 서식이 없다 | 다른 넷이 다 크거나 다르다 — `public-si` 공공 SI 산출물 · `agile-product` 애자일 제품 개발 · `cloud-native` 클라우드 네이티브 서비스 운영 · `ai-service` AI · LLM 서비스 |
| 이미 쓰던 문서가 있다 | 그 문서를 `docs/` 로 옮기고 등록부에 올린다 — 40종을 붓고 지우는 것보다 짧다 |
| 작업 기록부터 쌓는다 | `work/` 는 정본 문서 없이도 돈다. 자주 고치는 대상이 보이면 그때 관리 문서를 세운다 |

**서식 하나가 필요하면 그 패키지에서 문서 하나만 가져온다** — 배포본의 다른 `knowledge-repo-*`
폴더(서버형은 서버의 `packages/`)에서 그 파일 · 등록부 행 · 어휘 절을 옮긴다. 문서마다 끝의
`## 작성지침` 이 서식 규약이다.

## 붓는다

```
xcopy /E /I <배포본>\knowledge-repo-blank C:\cdp
copy <배포본>\cdp.exe C:\cdp\tools\
cd /d C:\cdp
git init && git config core.hooksPath .githooks
```

서버형은 콘솔 › 지식 레포 › 새 레포에서 `blank` 를 고른다. 부은 직후 `ctx check` 는 `이상 없음` 이다.

## 첫날 — 첫 관리 문서를 세운다

```
1  정본으로 둘 것 하나를 고른다     자주 바뀌고 여럿이 보는 것 — API · 테이블 · 화면 · 용어
2  좌표 타입을 정한다               문서 이름에서 딴다 (아래 「타입 이름」)
3  등록부 행 · 문서 · 어휘를 같이    셋 중 하나라도 빠지면 좌표가 안 잡힌다
4  ctx check                       이상 없음이면 그 타입부터 파생이 돈다
```

| | 어떻게 |
|---|---|
| 서버형 · 에이전트 | 「용어집을 관리 문서로 두자」 처럼 말한다 — `cdp-save` 의 【등록부 변경】 이 `save` 의 `managed`(등록부 행 · 문서) · `vocab`(타입 · 좌표) · `sections`(첫 섹션)를 **한 커밋**으로 낸다. 등록부를 바꾸는 save 는 사람의 승인을 받는다 |
| 셸(모드 A) | 아래 셋을 고치고 `bin/ctx index` → `bin/ctx check` → 커밋 |

셸로 「용어집」 을 세우면 —

```
_managed.md     표에 한 줄          | `용어:*` | `docs/용어집.md` | `## {값}` |
docs/용어집.md   문서                # 용어집 · 머리 표 · 섹션 `## 주문확정 — <뜻>` 바로 아래 <!-- applied: null -->
_vocab.md       타입 절과 좌표 줄    ## 용어   그 아래  - `용어:주문확정` — <뜻>
```

**머리 표의 `등록부` 칸과 `_vocab.md` 의 「지금 등록부」 블록은 손으로 쓰지 않는다** — `bin/ctx index`
(서버형은 save)가 `_managed.md` 에서 찍는다.

## 타입 이름

| 규칙 | 예 |
|---|---|
| **정본 문서 이름에서 딴다** — 서식 꼬리(정의서 · 명세 · 대장)를 뗀다 | 용어집 → `용어` · 인터페이스정의서 → `인터페이스` |
| 떼서 **보편적인 낱말**이 되면 떼지 않는다 — 어느 문서로 가는지 이름이 말해야 한다 | 테이블정의서 → `테이블정의서` · 화면설계서 → `화면설계서` |
| **한글로 시작하거나 영문 소문자**다 | `API:` · `SLO:` 같은 대문자 영문 타입은 MCP · 서버형 save 가 받지 않는다 |
| 값에는 공백이 없다 · ` - ` 를 쓰지 않는다 | 섹션 제목 `## <값> — <이름>` 의 ` — ` 앞이 값이다 |

## 이 패키지에 있는 것

| 파일 | |
|---|---|
| `_vocab.md` | 어휘 — 타입이 없다. 쓰는 법과 생성 블록만 |
| `_managed.md` | 등록부 — 머리 표만 |
| `docs/` | 빈 폴더(`.gitkeep`) — 관리 문서가 여기 선다. 깊이는 자유다(`docs/**/*.md`) |
