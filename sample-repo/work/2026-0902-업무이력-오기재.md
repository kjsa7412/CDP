# [오기재] 업무이력 분리 — 잘못된 테이블명

업무이력 상태를 `RP_WRK_HIST_STATUS` 로 분리한다고 기재했는데 실제 물리명은
`RP_WRK_HST_STAT_INFO` 다. 명명 규칙(`HST`·`INFO`)을 따르지 않은 이름을 적었다.

**2026-0903-업무이력-상태분리 가 이 기록을 대체한다.** 지우지 않고 남긴다 —
잘못된 이름으로 만든 스크립트가 어딘가 있을 수 있고, 그것을 찾을 단서가 필요하다.
