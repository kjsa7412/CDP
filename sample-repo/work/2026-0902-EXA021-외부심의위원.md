# EXA021 외부 심의위원 정보 — 코드헬프 신설

EXA021 '외부 심의위원 정보' 그리드를 정비한다. 컬럼은 성명·소속·직급·전화·이메일,
데이터는 `PS_EXT_EMP_MST` 에서 가져온다. **성명 팝업 코드헬프를 신설**하고
검색은 성명·전화(하이픈 없이)·이메일로 한다. '추가' 버튼 명칭을 **'선택'** 으로 바꾼다.

'추가' 는 신규 등록을 연상시키는데 실제 동작은 기존 외부인원을 **고르는** 것이다.
실제로 없는 사람을 새로 만들려다 문의가 들어왔다.

검색 항목 너비가 `gravity:1` 로 되어 있어 세 항목이 좁게 붙어 있었다. 전화번호는
하이픈 유무가 사람마다 달라 넓은 입력창이 필요하다.

선택 모달의 왼쪽은 `wrk_tp_cd`(PS130) 로 그룹핑한 외부인원 트리다.

남은 일 — PS130 업무구분 코드값 확정. 현재 연심회/평가위원회/위원회 3종만 확인됨.
