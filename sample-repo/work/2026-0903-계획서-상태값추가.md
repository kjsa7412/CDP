# 계획서 상태값에 반려(50) 추가

`PL010` 계획서 상태에 `50`(반려) 을 추가하고 `RP_PLND_MST.plan_stat_cd` 가
그 값을 받을 수 있게 했다.

반려된 계획서를 `10`(작성중) 으로 되돌려 쓰고 있었는데, 그러면 **한 번도 제출하지
않은 계획서와 반려되어 돌아온 계획서가 구분되지 않는다.** 통계에서 최초 제출률이
실제보다 높게 잡혔다.

PLA011 은 상태 배지와 버튼 활성 조건에 `50` 을 추가한다.
