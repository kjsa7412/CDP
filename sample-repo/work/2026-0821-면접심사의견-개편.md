# 면접심사의견등록(PSC043) 개편 — 현황/작성 화면 분리

PSC043 을 **현황 화면**과 **작성 화면** 둘로 나눴다. 현황은 응시자별 면접심사 대상
목록만 보여주고, 작성은 대상 1건을 골라 의견을 쓰는 전용 화면이다.

```
┌─────────────────────────────────────────────────┐
│ 헤더 : 심사위원(작성자) 정보                      │
├───────────────────────┬─────────────────────────┤
│ 첨부파일 리스트        │                         │
│  ● 자기소개서.pdf      │   의견 입력창            │
│ ────────────────      │   (넓게)                 │
│   [ PDF 뷰어 ]        │                         │
└───────────────────────┴─────────────────────────┘
```

심사위원이 화면 하나에서 목록을 보며 의견을 쓰게 했더니 **작업의 연속성이 끊겼다.**
응시자를 바꿀 때마다 그리드에서 행을 다시 찾아야 했고, 첨부파일을 별도 창으로 열면
의견 입력창이 가려졌다.

기존 오프라인 방식은 응시자 서류 묶음을 앞에 놓고 한 명씩 넘기며 쓰는 것이었다.
**그 동작을 화면이 그대로 흉내내야 한다** — 왼쪽에 서류, 오른쪽에 의견.

작성 화면에서 외부 심사위원을 고를 수 있어야 해서 `PS_EXT_EMP_MST` 에
업무구분(`wrk_tp_cd`)과 전화(`tel_no`)를 추가했고, 업무구분 코드그룹 PS130 을 신설했다.

9월 9일 정규직 심사 전에 한 번 써보고 실제 심사에 쓰겠다는 요구가 있어 개편 범위를
화면 분리와 뷰어까지로 한정했다. 평가 점수 체계는 손대지 않는다.

남은 일 — PDF 뷰어 컴포넌트 선정(사내 표준 없음), 연대서명 출력물 양식 인사팀 확인.
