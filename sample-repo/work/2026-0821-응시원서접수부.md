# 응시자 정보 전산 입력 — 응시원서 접수부 산출

응시자 정보를 PSC031 '응시자 정보 영역'에서 입력하고, 그 내용으로
**분야별 응시원서 접수부** 한글 문서를 생성한다.

현재 응시자 정보 입력 채널이 두 개다 — 서류심사관리의 응시자정보(전산)와
응시원서 접수부(한글 파일. 오프라인 수기). 둘이 어긋나면 어느 쪽이 정본인지
판단할 근거가 없다. 실제로 이미 채용이 진행 중이던 건은 첫 단계부터 넣기
애매해 수작업으로 밀어넣었다.

**전산을 정본으로 두고 한글 문서를 산출물로 뽑는 방향**이 맞다. 반대 방향(한글을
정본으로 두고 전산에 옮겨 적기)은 지금 상태 그대로다.

남은 일 — 접수부 한글 양식의 필수 항목과 PSC031 입력 항목 대조. **미완.**
