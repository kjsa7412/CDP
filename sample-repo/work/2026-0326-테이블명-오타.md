# 테이블명 오타 정정 — RP_RDC_OPL_mST → RP_RDC_OPL_MST

연심회의견서마스터의 물리명이 `RP_RDC_OPL_mST` 로 등록돼 있었다. `MST` 의 M 이
소문자다. `RP_RDC_OPL_MST` 로 정정했다.

PostgreSQL 은 인용부호 없는 식별자를 소문자로 접으므로 운영에는 지장이 없었다.
그런데 **테이블정의서·ERD·마이그레이션 스크립트는 이 문자열을 그대로 쓴다.**
정의서에서 `RP_RDC_OPL_MST` 로 검색하면 안 잡히고 없는 테이블로 판단하게 된다.

같은 작업에서 `RP_RDC_OPL_DTL`(구 상세) 을 마스터로 통합하고 어휘에
deprecated 로 표시했다.
