# 연구과제명 영문 검색 시 대소문자 무시

연구과제명 검색에서 영문을 대소문자 구분 없이 찾는다. `apec` 으로 검색해도
`APEC` 이 포함된 과제가 나온다.

과제명에 영문 약어가 들어가는 경우가 많은데(APEC, ODA, R&D) 사용자는 소문자로
친다. 현재는 `LIKE` 를 그대로 써서 대문자로만 걸린다.

**"검색이 안 된다"가 아니라 "그런 과제가 없다"로 읽힌다.** 조용한 실패와 같은
성질이라 우선순위를 올렸다.
