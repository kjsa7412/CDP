## SEC011 — 연관위심의등록
<!-- applied: 2026-0902-연관위-readonly -->

심의 건을 만들고 심의대상 과제와 위원을 지정한다.

| 그리드 | 매핑 |
|---|---|
| 심의대상연구과제목록 | `RP_RPMC_INSP_PRJ_LIST` |
| 심의대상자목록 | `RP_RPMC_INSP_TARGR_LIST` |

**저장 조건** — 심의대상연구과제목록 최소 1건, 심의대상자목록 최소 1명.
빈 row 는 대상자로 세지 않는다.

**저장·임시저장이 둘 다 불가능하면 화면 전체가 readonly 다.** 등록·삭제·추가
버튼이 **눌리지 않아야** 한다 — 눌리는데 아무 일도 안 일어나면 사용자가 시스템
오류로 판단하고 같은 동작을 반복한다.

**변경**
· 2026-03-24 [`연관위심의-스키마`](../work/2026-0324-연관위심의-스키마.md) 그리드 2개를 각각 다른 테이블에 매핑
· 2026-09-02 [`연관위-readonly`](../work/2026-0902-연관위-readonly.md) 저장 불가 상태의 readonly 규칙

## SEC014 — 연구관리위원회결과등록
<!-- applied: 2026-0902-야간배치-과제상태 -->

심의 결과를 위원 × 과제 단위로 등록한다. `RP_RPMC_INSP_EVL_LIST` 를 쓴다.

심의 확정 시 과제 상태는 야간 배치가 재계산한다 — 화면에서 즉시 바꾸지 않는다.

## PSC043 — 면접심사의견등록
<!-- applied: 2026-0821-면접심사의견-개편 -->

**현황 화면과 작성 화면 둘로 나뉜다.**

| 화면 | 역할 |
|---|---|
| PSC043 (현황) | 응시자별 면접심사 대상 목록. 진행 상태만 |
| PSC043P (작성) | 대상 1건을 골라 의견을 쓰는 전용 화면 |

작성 화면 — 헤더에 심사위원 정보, 왼쪽에 첨부 리스트와 PDF 뷰어, 오른쪽에 의견 입력창.
보훈 항목은 자동 합계, 주요 경력 항목은 제거됐다.

출력물 2종 — 연대서명(위원 전원 한 장) · 개인별 서명(1인당 한 장).

**변경** · 2026-08-21 [`면접심사의견-개편`](../work/2026-0821-면접심사의견-개편.md) 화면 분리 · PDF 뷰어 · 출력물 2종

## EXA021 — 심의위원 정보등록
<!-- applied: 2026-0902-EXA021-외부심의위원 -->

심의위원과 외부 심의위원을 등록한다.

| 그리드 | 컬럼 | 데이터 |
|---|---|---|
| 외부 심의위원 정보 | 성명·소속·직급·전화·이메일 | `PS_EXT_EMP_MST` |

- '추가' → **'선택'** 으로 명칭 변경 (기존 인원을 고르는 동작이다)
- 성명 팝업 코드헬프. 검색은 성명·전화(하이픈 없이)·이메일
- 선택 모달 왼쪽은 `wrk_tp_cd`(PS130) 그룹핑 트리

**변경** · 2026-09-02 [`EXA021-외부심의위원`](../work/2026-0902-EXA021-외부심의위원.md) 코드헬프 신설 · 버튼 명칭 · 컬럼 정비
